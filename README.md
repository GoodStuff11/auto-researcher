# auto-researcher

Given a research question, exhaustively searches academic literature and
produces a direct, cited answer — with everything found, scored, and read
persisted to a local store so it never needs to be requeried.

See [`auto-researcher/README.md`](auto-researcher/README.md) for setup,
usage (including the `/research-question` and `/research-followup` Claude
Code skills), architecture, and the full CLI reference.

Design rationale and implementation plans live under `docs/superpowers/`.
