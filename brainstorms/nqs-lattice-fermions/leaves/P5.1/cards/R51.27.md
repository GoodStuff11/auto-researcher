# R51.27 — size-transfer warm start of the larger cluster (tilewarm) (KILLED)
* **The idea**: Train the network on the smaller cluster, copy (tile or embed) its backflow weights into the larger cluster's network, and start the larger cluster's guided SR from there, so fewer optimisation steps, and so fewer total samples to 90% of the gap, are needed at the large size; the gain would grow with size if the trained small-cluster weights already encode the local correlations.
* **Lineage**: round 16 batch, orchestrator's direction (b); same mechanism as P4.1 R15c and P4.2 R9.6 (both killed).
* **Outcome**: KILLED at T0 (2026-11-18).
* **Kill rule**: T0: does the warm start act on the part of the run where this leaf's samples are spent (the late tail measured by R51.8 and R51.16), and can the `che` network take it?
* **Evidence**: (i) every P5.1 measurement already starts from an SR-trained state (1000 exact-sum SR iterations at each size, `starts/*.json`; relative error 5.5e-4 at 5×2, 1.1e-3 at 6×2), and all counted draws are spent after it: guided 16,384 needs 4.51M draws to a sustained 90% at 12 sites from that start (R51.16). (ii) `che` has a global MLP whose input and output sizes depend on the site count, so nothing tiles (P4.1 R15c). (iii) Where transfer was built (P4.2), transferred states were worse than mean field (R3.1) and the head start of a transferred initialiser was used up within the first tens of steps, a speed-up of about 1 (R9.6, L43).
* **Why this kills it**: the barrier is the samples per step needed near the representable minimum; a warm start can only replace the early transient, which the SR-trained start has already removed for free in this accounting, and the transferable start that exists is worse than that start.
* **What the kill does not rule out**: warm starts for translation-invariant (convolutional or transformer) backflows, where weights are size-independent; transfer of the step's preconditioner or sampler settings rather than the state.
* **Strongest case against the kill**: a transferred state could land in a better basin, so the tail itself is shorter. Unresolved; P4.2 found no transferred state below a trained one.
* **Checked by**: not yet reviewed (worker gate, round 16).
* **Lesson**: L43 (a warm start must beat its own start and training from scratch); route-specific otherwise.
