# R44 — converged exactly projected charge-only vs spin-reading comparison at 16 sites (conv-16) (KILLED)
* **The idea**: Run the R40 comparison (one NNBF, input charges for `che` vs spins for `nnbf_SG`, both projected exactly onto $S=0$ and the point-group irrep) one size up, on a 16-site $4\times4$ cluster with an exact reference, trained with the P5.1 optimiser (guided SR, fixed short step, 262,144 samples per step, which reached 99% of the polished 12-site state, R51.1), so both arms end near convergence and the ratio measures expressivity rather than optimiser progress (L33).
* **Lineage**: round-30 batch, item (a) of the brief; Operation A on R40 (refused at 12 sites, L39). Its affordable form is folded into R45 as an optional point.
* **Outcome**: KILLED at G4 (T0, 2026-11-17).
* **Kill rule**: Gate 4: does it say anything beyond 16 sites, at a cost the leaf can pay?
* **Evidence**: operation counts, on CPU (R51.1's single-core step; the orbit sum batches well on a GPU, which shifts the constants but not the exponential growth in $N_s$). (i) Hubbard $4\times4$, $N_e=12$–14, sampled: the projected spin-reading amplitude sums the spin orbit, $\binom{N_s}{N_s/2}=252$–924 network amplitudes at typical $N_s=10$–12, and each local energy needs about 50 amplitudes, so a 262,144-sample step costs about 500× R51.1's 2.2 CPU-min `che` step: about 18 CPU-h per step. (ii) Hubbard $4\times4$ $6+6$, exact sums: 64M configurations, about 100× the 12-site 627,264, so about 6.5 CPU-min per exact gradient (12 sites: 3.9 s) and about 430 CPU-h per 4000-iteration arm. (iii) The cheap 16-site cluster is the open $4\times4$ $t$–$t'$–$J$ $6+6$ (1.68M configurations, projected NNBF code of P1.1/P1.3, $d_{S\chi}=30220$): about 10 s per gradient, but exact sums dominate any sampled optimiser there, `che` would read holes only, and the model change breaks any trend with the 12-site Hubbard data.
* **Why this kills it**: the affordable version is an exact-sum cluster (L39) and says nothing beyond 16 sites; a sampled Hubbard version is exponential in $N_s$ by the commutant lemma, the leaf's barrier itself. One more ED point on another model is not a size trend, and it inherits R40's refusal reasons (fitted tails make AMBIGUOUS likeliest).
* **What the kill does not rule out**: a 16-site $t$–$J$ point inside a capacity probe that is shown to converge (R45); comparisons whose spin-reading arm is not projected exactly (R42, R43, R47).
* **Strongest case against the kill**: $4\times4$ is the first cluster with bulk 2D sites, so more representative than $4\times3$ (L40). Answered: representativeness is not reach; an exactly projected spin-reading arm costs $\binom{N_s}{N_s/2}$ amplitudes per amplitude, out of this CPU budget beyond about 16 sites at these fillings.
* **Checked by**: per-leaf critic, 2026-11-17: upheld; lesson rescoped (objections 3, 6).
* **Lesson**: proposed library entry: a two-sided expressivity comparison against an exactly projected spin-reading network costs $\binom{N_s}{N_s/2}$ amplitude evaluations per amplitude ($N_s$ singly occupied sites); on a CPU budget of hundreds of hours this limits it to about 16 sites near the fillings tried ($N_s\lesssim12$). Beyond that only one-sided tests (unprojected, symmetrised or penalised comparator; fidelity to an $S=0$ teacher whose $\langle S^2\rangle$ is checked) are possible, and they can show a loss but not its absence (R46, R47). A budget statement, not a structural one: at strong doping $N_s$ is small.
