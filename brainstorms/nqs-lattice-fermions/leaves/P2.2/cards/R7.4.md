# R7.4 — Variational product-weighted screening in localized orbitals (C3′) (KILLED)
* **The idea**: Combine R7.1's variational certificate with R7.3's localized basis: in Löwdin orbitals the dropped elements decay with distance, so the certified excess per dropped term falls too, and the certified kept fraction could fall with size while the energy stays a rigorous upper bound. Its non-diagonal form adds a compensator $C$ supported on the diagonal and the kept pairs, with $C-H_{\mathrm{drop}}\succeq0$, so that screening keeps a variational guarantee.
* **Lineage**: reopening review, merge of C3 (R7.3) with C1 (R7.1); its non-diagonal follow-up was tested by a T1 SDP bound, an H$_8$ robustness test, a T1b on real trained states and a T0 operation count (2026-11-17). No successor.
* **Outcome**: KILLED at T0 (2026-11-17, cost).
* **Kill rule**: the leaf's acceptance condition, fixed before any route: an estimator qualifies only if its cost to a fixed error bar is below EXACT's and falls relative to EXACT as the basis grows, at bias ≤$\tau=0.2$ mHa; at T0 the cost is an operation count of the real algorithm per sample (L47). No further numeric rule was written; applied by the orchestrator.
* **Evidence**: H$_6$ SDP bound: certified kept fraction 0.134, 0.44× plain localized screening: PASS-T1. H$_8$ path gadget (relative noise $10^{-2}$): 0.0602 against KILL line 0.433: PASS-T1 (additive noise: 23–125$\tau$). NNBF-J trained states: excess 0.00–0.03$\tau$: PASS-T1b. T0 count (H$_8$): 360 connected terms per sample, 27 kept, but the compensator needs reference amplitudes on about 1352 determinants; frozen-NQS reference about 3.8× EXACT (about 1.5× at the grid end $\varepsilon=0.1$); Jastrow–HF reference (0.1× EXACT) estimated too inaccurate ($\delta\approx0.3$–1 vs ≤0.17 needed; measurement running in `tests/P2.2_stochastic_local_energy_r8/jhf_reference.*`); HF or CAS references vanish on most determinants. Full numbers: log/legacy.md (card snapshot, 2026-11-17).
* **Why this kills it**: the certificate is cheap only if the slack $Y=D^{-1}LD^{-1}$ can be evaluated per sample, and $Y$ couples each sample to determinants several kept edges away (about 1352 at H$_8$ against 360 calls for EXACT). Every reference either costs more than EXACT, is estimated too inaccurate, or vanishes where needed (falling back to the failed diagonal certificate), so no admissible version is cheaper than EXACT.
* **What the kill does not rule out**: accuracy holds only on states trained to $\Delta E\le0.03$ mHa (H$_8$ excess 9–16$\tau$ at the working $\approx0.74$ mHa), so a cheap nonzero reference (relative error ≤0.17 at ~0.1× EXACT) revives it only if the certificate also stays below $\tau$ there. Not covered: ED-size precomputation of $L$, amortising references along a Markov chain where kept balls overlap.
* **Strongest case against the kill**: cache the reference work across samples. At H$_8$ the 3-ball is 28% of the sector, so caching is near-full enumeration; beyond ED the ball should grow faster than $\lvert\mathcal C\rvert$ (argued, not measured); the 1352 count is conservative. Unresolved for a reference network designed for this purpose.
