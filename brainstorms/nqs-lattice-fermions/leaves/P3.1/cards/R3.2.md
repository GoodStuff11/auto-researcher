# R3.2 — Hylleraas-trained response network (ZR, Route 3.2) (KILLED)
* **The idea**: Train a second projected network to maximise the Hylleraas quotient whose maximiser is the first-order response $y^*=\tilde K^{-1}(\hat A-a)\psi$, then report the zero-bias contraction $\hat\delta=2\langle r\vert y\rangle$ with the residual $r$. Because the response is a separate network it lies outside the tangent space, so it is not blind.
* **Lineage**: Operation A.1 on R2.1 (Round 3). Descendants: R5.1 (closed-form version), R8.1, and the self-consistent response line R10.1 to R10.1d.
* **Outcome**: KILLED at CRITIC (2026-11-12)
* **Kill rule**: Round 3 per-leaf critic: Gate 0 and the round-5 requirement "no extra NQS per observable".
* **Evidence**: It is the Assaraf–Caffarel zero-bias correction with a trained improved function, and it needs one network per (observable, distance). The smoke showed the first-order oracle over-stating $\delta$ by 1.5–2.2 at infidelities 0.02–0.2. Round 8 later showed the same algebra fails like R8.1.
* **Why this kills it**: Not new as an estimator, and its cost per observable was judged prohibitive at the time.
* **What the kill does not rule out**: A response class that is iterated and base-updated (R10.1u, R10.1d), which later passed T1 and T2.
* **Strongest case against the kill**: The cost of one response network does not grow with $V$, unlike excited-state windows (corrected by R8.1). Accepted in Round 8; the line was revived.
* **Checked by**: per-leaf critic, Round 3 (2026-11-12); revisited Round 8.
