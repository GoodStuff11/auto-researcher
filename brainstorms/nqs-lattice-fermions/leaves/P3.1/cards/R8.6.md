# R8.6 — Extrapolation in the window size (Route 8.6) (KILLED)
* **The idea**: Run the excited-state window at several sizes $K$ and extrapolate the recovered error in $K$ to infinity, so a small affordable window predicts the full correction without training all the needed levels.
* **Lineage**: Round 8.
* **Outcome**: KILLED at T0 (2026-11-16)
* **Kill rule**: T0 argument (S1′).
* **Evidence**: The out-of-window error $\langle c_{\mathrm{out}},a\rangle$ and the window data are different linear functionals of $c_{\mathrm{out}}$; with more than $K+1$ out-of-window levels some perturbations move $\delta$ and leave every window datum unchanged at first order.
* **Why this kills it**: Any extrapolation needs a model of the out-of-window error, which is the unknown.
* **What the kill does not rule out**: Extrapolation with a validated model of $c_{\mathrm{out}}$.
* **Strongest case against the kill**: None.
* **Checked by**: worker T0 argument, Round 8.
