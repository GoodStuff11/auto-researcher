# R2.3 — Linear first-order bond dressing (Route 2.3) (KILLED)
* **The idea**: Condition the correction on the reference by applying a linear dressing $\langle\mathbf n\rvert(1+\sum_b\alpha_b(\mathbf n)\hat K_b)\lvert\Phi\rangle$, where $\hat K_b$ hops across bond $b$ and $\alpha_b$ comes from a network, so each configuration's amplitude mixes in its neighbours' reference amplitudes and can change sign.
* **Lineage**: Operation A.1 from R2.1 (Round 2, 2026-11-11); its kill fed R2.2 ("make it a product").
* **Outcome**: KILLED at G0 (2026-11-11).
* **Kill rule**: Gate 0 (known; adoption barrier fixed?) and Gate 1 (asymptotics).
* **Evidence**: with uniform $\alpha$ it is the one-step Lanczos or power step (Sorella, PRB 64, 024512 (2001); Becca et al., arXiv:1412.2656; used on NNBF by Loehr & Clark, arXiv:2510.26906). arXiv:1412.2656 states that a fixed number of Lanczos steps is not size-consistent.
* **Why this kills it**: the correction is a sum of $\mathcal O(V)$ terms against a fixed 1, so its relative effect on an intensive quantity vanishes as $V\to\infty$; a configuration-dependent $\alpha$ does not change that.
* **What the kill does not rule out**: multiplicative (product) versions of the same neighbour information (R2.2).
* **Strongest case against the kill**: at ED sizes a linear step can still help. Not raised by a critic; true but irrelevant, since the Hard Core concerns growing $V$.
