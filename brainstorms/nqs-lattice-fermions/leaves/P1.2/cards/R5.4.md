# R5.4 — FRD-F, frozen-frame ratios to remove FRD's cost wall (Routes 5.4 and 6.1) (KILLED)
* **The idea**: Make FRD cost the same as NNBF by taking each ratio from the base's backflowed orbitals frozen at $\mathbf n$, $R^F_e=c_e\det O_{\mathbf n}[\mathrm{rows}(\mathbf m_e)]/\det O_{\mathbf n}[\mathrm{rows}(\mathbf n)]$, one Sherman–Morrison update instead of a full NNBF pass per neighbour.
* **Lineage**: Operation A.1 on R5.1's cost wall (Round 5, held; re-gated as Route 6.1 in Round 6, 2026-11-16).
* **Outcome**: KILLED at T2 (2026-11-16, job 697584).
* **Kill rule**: pre-registered T2-b: $u=(\Delta E_{\mathrm{sign}}[F^F]-\Delta E_{\mathrm{sign}}^{K})/\mathrm{gap}$; "DROP-IN-PASS if $u\le0.25$, KILLED if $u\ge1$".
* **Evidence**: substituting frozen ratios into the trained FRD-K state gave $\Delta E_{\mathrm{sign}}=0.0132$ against 0.00975 for FRD-K and 0.0120 for the control ($u=1.50$), and doubled $\Delta E_{\mathrm{tot}}$. Its cost passes Gate 4 (wall-time ratio flat at 2.2, slope $-0.05$). Frozen ratios have median error 23% against exact ones.
* **Why this kills it**: the read-out loses all of FRD-K's gain, and, as the critic re-based it, FRD-F exists only to make the vote cheap, while T2-a showed the vote is unused.
* **What the kill does not rule out**: a retrained FRD-F (the drop-in test used weights trained for exact ratios), and frozen ratios as learned features (R7.2).
* **Strongest case against the kill**: a drop-in failure does not show that a retrained FRD-F fails (round-6 critic objection 5). Answered by re-basing the kill on VOTE-INERT.
* **Checked by**: round-6 per-leaf critic (2026-11-16, objection 5).
* **Lesson**: route-specific — dies with the unused vote it was built to cheapen.
