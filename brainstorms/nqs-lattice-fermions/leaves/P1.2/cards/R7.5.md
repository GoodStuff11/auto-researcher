# R7.5 — Gated mixture of NNBF experts (Route 7.5) (KILLED)
* **The idea**: Write $\psi=\sum_k\pi_k(\mathbf n)\Phi_k(\mathbf n)$ with a softmax gate over several NNBF experts, so a sign changes where the gate switches between experts with different nodes, without any single determinant crossing zero.
* **Lineage**: Operation B.3, cross-field translation from machine-learning mixtures of experts (round-6 critic refill, 2026-11-16).
* **Source analogy**: In machine learning, mixtures of experts (Jacobs, Jordan, Nowlan & Hinton, Neural Comput. 3, 79 (1991)) let a gate pick a specialist per input. Correspondence: expert ↔ one NNBF with its own nodes; gate ↔ region of configuration space. It worked there because inputs cluster into a few regimes; the gap is that independent local sign repairs in many regions combine multiplicatively.
* **Outcome**: KILLED at G4 (2026-11-16).
* **Kill rule**: Gate 4: does its cost survive growing $V$?
* **Evidence**: $R$ independent repairs in distant regions need $2^R$ experts, or a gate that factorizes over regions, which is a CPS sign correlator (R2.1's kill). It is also a sum of determinants (Anti-Solution Space item 1).
* **Why this kills it**: the number of experts grows exponentially with the number of independent repairs, which grows with $V$.
* **What the kill does not rule out**: a few experts for a few global sectors (for example competing orders), which is not a sign-repair mechanism.
* **Strongest case against the kill**: repairs might not be independent. Not raised by a critic; unresolved.
