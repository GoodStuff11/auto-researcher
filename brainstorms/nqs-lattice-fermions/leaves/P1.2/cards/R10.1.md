# R10.1 — Span-S phase carrier: a linear phase on cross-site ratio products (reopening-ledger row 4) (KILLED)
* **The idea**: Put a phase $e^{i\varphi(\mathbf n)}$ on the frozen trained backflow, with $\varphi$ linear in a span S that adds cross-site products of the per-site features on every bond and two-hop products of edge ratios to R9.1's per-site span. R9.1 failed because every per-site span had positive curvature; the descending phase directions vary across pairs of neighbouring edges, so a span that couples edges might contain one and let the carrier rotate wrong signs to right ones without any zero crossing.

* **Why this kills it**: $r\ge0.9$ at both counted sizes, so KILL fires, despite 10–12 times width's added parameters (1464 and 1760 against 145), so the loss holds a fortiori; S contains every weight-shared linear carrier on these columns, so a matched-parameter one can only do worse. Its gain sits on near-node flips and flip-free phase, not on nodal errors.
* **What the kill does not rule out**: carriers non-linear in these columns or on other features (message passing, longer hops); carriers trained jointly with the backflow; projected foils; sizes above 12; spans passing the amended curvature screen ($q/\max\lvert g\rvert^2$).
* **Strongest case against the kill**: the screen said OPEN ($\lambda(S)$ strongly negative where every earlier span was positive). Answered by the licensed training: it lost to width, its flips were near-node, and post-hoc diagnostics show the negative $\lambda$ came from near-node spikes.
