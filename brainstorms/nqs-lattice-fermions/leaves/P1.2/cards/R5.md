# R5 — Neural Pfaffian of a learned pairing matrix (Route 5) (KILLED)
* **The idea**: Use the Pfaffian of a configuration-dependent pairing matrix produced by a network, so the antisymmetric object is a pairing state with learned, non-mean-field structure rather than a backflow Slater determinant, hoping pairing nodes are less anchored.
* **Lineage**: initial batch (Round 1, 2026-11-10); not mutated.
* **Outcome**: KILLED at G0 (2026-11-10).
* **Kill rule**: Gate 0: is it new, and does it fix the reason it is not standard?
* **Evidence**: Neural-network-augmented Pfaffians (Chen et al., arXiv:2507.10705) and Neural Pfaffians (Gao & Günnemann, arXiv:2405.14762) are this construction.
* **Why this kills it**: a relabelling; its nodes still move only by deforming a pairing matrix through zero, the same orbital-anchored barrier as backflow.
* **What the kill does not rule out**: Pfaffians as the base of a sign layer that adds a new mechanism.
* **Strongest case against the kill**: the lattice $t$–$J$ use may differ from the continuum work. Not raised by a critic; unresolved, but no mechanism was offered.
