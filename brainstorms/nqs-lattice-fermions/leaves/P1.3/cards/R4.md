# R4 — Hamiltonian continuation from the sign-free or non-interacting limit (round-1 Route 4) (KILLED)
* **The idea**: Anneal a Hamiltonian parameter (the interaction $U$ from 0, the next-nearest hopping $t'$ from 0, or a path from a sign-free to a signful model) and warm-start each step from the last, so the network follows the ground state continuously from a limit where its sign is known.
* **Lineage**: initial batch (round 1). Mutated in round 3 into R3.3 (tracking both diabatic branches).
* **Outcome**: KILLED at G0 (2026-11-10; it also failed G3).
* **Kill rule**: Gate 0 (known, adoption barrier not fixed) and Gate 3 (does it work only by removing the Hard Core?).
* **Evidence**: Starting from the $U=0$ Slater determinant already is continuation from the non-interacting point and is the default. Annealing in Hamiltonian parameters is common, and its known failure is that it follows the metastable branch through first-order level crossings. The Hard Core consists of exactly such crossings between near-degenerate competing orders.
* **Why this kills it**: The route adds nothing to the default start and inherits its failure at the crossings it must pass.
* **What the kill does not rule out**: paths that start inside the target phase rather than at the non-interacting point, and continuation that tracks several branches (R3.3, killed separately at G0).
* **Strongest case against the kill**: a path in $t'$ that starts where the desired order is the ground state could stay on the right branch (not raised by a critic). Unresolved here; it needs knowledge of the target phase, which is what the problem lacks.
