# R6.4 — Hierarchical local-hidden-row HFDS, Tree-HFDS (Route 6.4) (KILLED)
* **The idea**: R6.1′ plus one hidden fermion per block of a $2^\ell\times2^\ell$ block hierarchy, each with nonlinear block features computed from its children. A hop changes the local rows plus $\mathcal{O}(\log V)$ ancestor rows, so $C_E=\mathcal{O}(N_e^2F(b+\log V))$, and coarse rows are nonlinear in whole-block content, which a purely local patch lacks.
* **Lineage**: Operation A on R6.1′'s sharpest gap, and translation repair of R2.6 (its pooled linear far field replaced by nonlinear block features), round 6.
* **Source analogy**: fast multipole and hierarchical matrices (Greengard and Rokhlin 1987; Hackbusch 1999), as for R2.6; the repair replaces linear pooled far-field channels (the B2 weakness) with nonlinear block features. The translation gap that remained is testability: exact-sum clusters have almost no hierarchy.
* **Outcome**: KILLED at G3 (2026-11-16, Gate 3 for testing, round-6 critic Major 3).
* **Kill rule**: Gate 3 for testing: can the added mechanism be measured on an exact-sum instance against a foil that isolates it?
* **Evidence**: coarse levels exist only while $2^\ell$ divides the side length; on instance 4 ($5\times3$) there is none, so the T2 would test plain R6.1′, and on $4\times4$ the root row is one global nonlinear hidden unit, which is NNBF's mechanism. T1 had passed (exactness $2.4\times10^{-15}$, timing slope 0.66).
* **Why this kills it**: no affordable exact-sum test can attribute a gain to the hierarchy, the R2.6 situation.
* **What the kill does not rule out**: the hierarchy tested by variational Monte Carlo at $8\times8$ or larger against NNBF with variance-extrapolated energies.
* **Strongest case against the kill**: the hierarchy matters only at large size; accepted, which is why the kill is scoped to exact sums.
