# R7.4 — Linear-attention backflow with a global summary (Route 7.4) (KILLED)
* **The idea**: Orbital rows $\Phi_0[x_j]+\phi(q_j)^{\top}SW$ with a global summary $S=\sum_k\phi(k_k)v_k^{\top}$ of all tokens, as in linear attention. A hop changes $S$ by rank $\mathcal{O}(1)$, so ratios stay cheap while every row sees the whole configuration.
* **Lineage**: Operation B.3, cross-field translation from machine learning (round 7).
* **Source analogy**: linear attention (Katharopoulos et al., ICML 2020, arXiv:2006.16236) replaces softmax attention by a kernel feature map so that a global key–value summary updates by rank one per token; it works because the summary is linear in the tokens. Translation gap: a linear readout of a fixed-size summary has bounded rank, which is the GK-BF trap.
* **Outcome**: KILLED at G4 (2026-11-16, T0).
* **Kill rule**: Gate 4: is the sign capacity size-consistent at fixed width, within the F1 cost bound?
* **Evidence**: a linear readout of $S$ makes the global correction rank at most $\dim\phi$, one fixed-size hidden-fermion factor shared by all blocks (as R6.1); a nonlinear readout changes every row per hop, which is the F1 bound $C_E=\Omega(N_e^3)$.
* **Why this kills it**: either branch fails a frozen boundary condition.
* **What the kill does not rule out**: attention with local key–value windows feeding local hidden rows.
* **Strongest case against the kill**: none raised; it is an identity plus the F1 bound.
* **Checked by**: not separately reviewed; the Round 11 per-leaf critic (2026-11-16) read the leaf from Round 6 on and did not contest it.
