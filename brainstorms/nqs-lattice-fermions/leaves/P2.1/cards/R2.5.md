# R2.5 — Delayed-acceptance two-stage Metropolis (Route 2.5) (KILLED)
* **The idea**: Screen each Metropolis proposal with the cheap restricted family and evaluate the expensive full NNBF ratio only for proposals that survive the screen, keeping detailed balance through the second-stage correction. This lowers the cost per accepted move while sampling the exact full-family distribution.
* **Lineage**: Operation B.2 (active probing), cross-field translation from computational statistics, round 2; re-proposed as R13.6.
* **Source analogy**: delayed-acceptance MCMC (Christen and Fox, J. Comput. Graph. Stat. 14, 795, 2005) uses a cheap surrogate posterior to reject most proposals before the expensive likelihood; it works when the expensive evaluation is needed only for acceptance. Correspondence: posterior is $\lvert\psi\rvert^2$, surrogate is the restricted family. Translation gap: VMC also needs the local energy, which uses every connected ratio of the full family.
* **Outcome**: KILLED at G1 (2026-11-11).
* **Kill rule**: Gate 1: does the route meet the complexity bound F1 for the local energy?
* **Evidence**: $E_{\mathrm{loc}}$ needs all $\mathcal{O}(zN_e)$ full-family ratios, so $C_E=\Omega(N_e^3)$ is untouched; replacing them by surrogate ratios is biased.
* **Why this kills it**: it saves only on acceptance, which is not where the cost lies.
* **What the kill does not rule out**: delayed acceptance as a constant-factor tool where acceptance dominates.
* **Strongest case against the kill**: none raised; the cost argument is an operation count.
* **Checked by**: round-2 per-leaf critic (2026-11-11).
* **Lesson**: route-specific — the local energy, not acceptance, is the cost.
