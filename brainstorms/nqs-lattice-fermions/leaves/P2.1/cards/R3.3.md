# R3.3 — Image-table projected SK-LR (Route 3.3) (KILLED)
* **The idea**: Symmetry projection averages the amplitude over the $\lvert G\rvert$ images of the configuration under the lattice group. With a reference whose column span is group-invariant, one carried inverse serves all images, and only $\lvert G\rvert K$ extra table columns are needed, so projection would cost little extra.
* **Lineage**: Operation A on R2.1's carried-table component, aimed at the projection-cost wall (round 3); mutated into R6.3.
* **Outcome**: KILLED at G1 (2026-11-12).
* **Kill rule**: Gate 1: does the operation count, including the network, support the claim?
* **Evidence**: the network forward $C_k(g\mathbf n')$ costs $\mathcal{O}(H_sKrN_e)$ per image and connection, the same as separate tables, so the local energy is unchanged; with translations $\lvert G\rvert\propto V$ adds a factor $N_e$ either way.
* **Why this kills it**: the saving is in memory and the sweep only, not in the dominant term.
* **What the kill does not rule out**: an equivariant trunk whose image forwards are permutations of one forward (R6.3).
* **Strongest case against the kill**: none raised; it is an operation count.
* **Checked by**: round-3 per-leaf critic (2026-11-12).
* **Lesson**: route-specific — per-image forwards dominate.
