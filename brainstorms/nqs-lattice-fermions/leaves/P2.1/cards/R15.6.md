# R15.6 — Learned sparse gating of hidden rows (Round 15.6) (KILLED)
* **The idea**: Let the network decide, per configuration, which hidden rows are active: row $m$ contributes $K[:,m]\,g_m(\mathbf n)\,h_m\Omega_m$ with a patch-local gate $g_m=\mathrm{ReLU}(w\cdot x_m+c_{s(m)})$ ($c$ depends on the sublattice $s(m)$), so inactive rows are exactly zero and drop out of the carried matrix, while a penalty holds the mean active fraction at 1/2. The family contains `half` (gate set by sublattice) and hole-gated rows (gate set by occupation), so at the same active fraction it can match or beat both, while its cost follows the active count, not $V$.
* **Lineage**: Operation B (adaptive placement) after the R12.3 and R13.2 kills, which showed that fixed and hand-ruled placements both lose capacity; also a cross-field translation from conditional computation in machine learning, Round 15. No successor.
* **Source analogy**: source problem: large networks are too expensive to run in full on every input. Correspondence: hidden rows = experts; the gate $g_m$ = the router; active fraction = expert sparsity. Why it worked there: a learned router spends computation only where the input needs it, and ReLU routing with an L1 penalty gives continuous outputs with controllable sparsity. Translation gap: experts in a mixture are summed independently, while active rows here enter one determinant, so a row entering or leaving changes the carried matrix's dimension (vertex insertion and removal, as in continuous-time impurity QMC), and the cost gain needs trained gates to stay at half activity. Citations: Shazeer et al., arXiv:1701.06538 (2017); Wang, Chen and Zhu, ReLU routing for mixtures of experts, arXiv:2412.14711 (2024); Gull et al., Rev. Mod. Phys. 83, 349 (2011).
* **Outcome**: KILLED at T1 (2026-11-17).
* **Kill rule**: pre-registered (Round 15, before any run): on instance 23 ($V=12$, `full_F4` $\Delta E_{\mathrm{sign}}=7.95\times10^{-3}$), Round 12 protocol unchanged (unprojected exact-force SR, seed 11, $F=4$, plateau test) plus a constraint holding the active fraction at 0.5; KILL if $\rho(12)>1.59$ (no better than `half_F4`, its own sub-family) or if $\rho(12)>1.25$ and the run is converged; INCONCLUSIVE if the final active fraction exceeds 0.55 or the plateau is not reached within 480 CPU-seconds.
* **Evidence**: `tests/P2.1_subcubic_amplitudes_r15/`, about 7 CPU-minutes interactive. Run 1 (adaptive L1 controller) oscillated (active fraction 0.21–0.88) and was declared invalid in `RULE.md` Addendum A, written before run 2. Run 2 (a bias shift holding the active fraction at 0.5): plateau at step 750, active fraction 0.495, $E-E_0=0.142$, $\Delta E_{\mathrm{sign}}=2.05\times10^{-2}$ against `full_F4`'s $7.95\times10^{-3}$, so $\rho(12)=2.57$, against 1.59 for plain `half_F4` (whose total error is 0.078). Per accepted hop on the trained state: 3.81 rows changed and 1.75 gate flips.
* **Why this kills it**: $\rho(12)=2.57>1.59$ fires the first clause: at half activity the learned placement ended worse than the fixed sublattice it contains, in sign error and in total error, so the route has no accuracy case at $V=12$ and its cost case (which needed it to beat `half`) is moot.
* **What the kill does not rule out**: a gate initialised at the sublattice pattern (which guarantees at least `half`'s value, then can only improve), other active fractions, wider rows, and other gate optimisers; the measured update statistics (3.81 rows and 1.75 flips per hop) would still allow a cost case if accuracy were recovered.
* **Strongest case against the kill**: the family contains `half`, so ending worse than `half` is an optimiser failure (L33), not a capacity limit. Unresolved; but `half` itself is killed (R11.1, R12.3), so matching it would not pass the route, which needs $\rho\le1.25$, and nothing in the run approached that.
* **Checked by**: orchestrator, 2026-11-17 (pre-registered rule applied; Addendum A registered before run 2); no per-leaf critic yet.
* **Lesson**: L33 (`library.md`): separately trained arms compare optimisers as well as families; here a superset trained from scratch ended below its own subfamily.
