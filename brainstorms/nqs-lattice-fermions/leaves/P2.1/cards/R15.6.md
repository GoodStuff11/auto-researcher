# R15.6 — Learned sparse gating of hidden rows (Round 15.6) (KILLED)
* **The idea**: Let the network decide, per configuration, which hidden rows are active: row $m$ contributes $K[:,m]\,g_m(\mathbf n)\,h_m\Omega_m$ with a patch-local gate $g_m=\mathrm{ReLU}(w\cdot x_m+c_{s(m)})$ ($c$ depends on the sublattice $s(m)$), so inactive rows are exactly zero and drop out of the carried matrix, while a penalty holds the mean active fraction at 1/2. The family contains `half` (gate set by sublattice) and hole-gated rows (gate set by occupation), so at the same active fraction it can match or beat both, while its cost follows the active count, not $V$.
* **Lineage**: Operation B (adaptive placement) after the R12.3 and R13.2 kills; also a cross-field translation from conditional computation in machine learning, Round 15. No successor.
* **Source analogy**: mixture-of-experts routing: hidden rows = experts, gate = router, active fraction = expert sparsity; a learned ReLU router with an L1 penalty spends computation only where the input needs it. Gap: active rows enter one determinant, so a row entering or leaving changes the carried matrix's dimension (vertex insertion and removal, as in continuous-time impurity QMC). Citations: Shazeer et al., arXiv:1701.06538; Wang, Chen and Zhu, arXiv:2412.14711; Gull et al., Rev. Mod. Phys. 83, 349 (2011).
* **Outcome**: KILLED at T1 (2026-11-17).
* **Kill rule**: pre-registered (Round 15): on instance 23 ($V=12$, `full_F4` $\Delta E_{\mathrm{sign}}=7.95\times10^{-3}$), Round 12 protocol plus active fraction held at 0.5; KILL if $\rho(12)>1.59$ (no better than `half_F4`) or if $\rho(12)>1.25$ and converged; INCONCLUSIVE if the final active fraction exceeds 0.55 or no plateau within 480 CPU-s.
* **Evidence**: `tests/P2.1_subcubic_amplitudes_r15/`, about 7 CPU-minutes. Run 1 (adaptive L1 controller) oscillated and was declared invalid in `RULE.md` Addendum A before run 2. Run 2: plateau at step 750, active fraction 0.495, $\Delta E_{\mathrm{sign}}=2.05\times10^{-2}$, so $\rho(12)=2.57$ against 1.59 for plain `half_F4`; per accepted hop 3.81 rows changed, 1.75 gate flips. Details: log/legacy.md (card snapshot, 2026-11-17).
* **Why this kills it**: $\rho(12)=2.57>1.59$ fires the first clause: at half activity the learned placement ended worse than the fixed sublattice it contains, in sign and total error, so it has no accuracy case and its cost case is moot.
* **What the kill does not rule out**: a gate initialised at the sublattice pattern, other active fractions, wider rows, other gate optimisers; the update statistics would still allow a cost case if accuracy were recovered.
* **Strongest case against the kill**: the family contains `half`, so ending worse is an optimiser failure (L33). Unresolved; but `half` itself is killed (R11.1, R12.3), so matching it would not pass ($\rho\le1.25$ needed), and nothing approached that.
* **Checked by**: orchestrator, 2026-11-17 (rule applied; Addendum A registered before run 2); no per-leaf critic yet.
* **Lesson**: L33 (`library.md`): a superset trained from scratch ended below its own subfamily.
