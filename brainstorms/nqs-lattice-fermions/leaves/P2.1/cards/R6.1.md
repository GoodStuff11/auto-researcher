# R6.1 — Global-kernel linear-readout backflow, GK-BF (Route 6.1) (KILLED)
* **The idea**: Orbital row $j$ is a mean-field orbital plus $K[x_j,:]H(\mathbf n)\Omega$, with local features $H$ from patches, a trainable site-to-site kernel $K$ and a shared readout $\Omega$. A hop changes $H$ on a few sites only, so the matrix changes by rank $1+b$, and the global kernel makes the correction long-range at $\mathcal{O}(N_e^2)$ local energy.
* **Lineage**: Operation A on R2.6 and R3.4 (round 6); mutated into R6.1′.
* **Outcome**: KILLED at G4 (2026-11-16, T0, found after its T1 run).
* **Kill rule**: Gate 4: is the sign capacity extensive (size-consistent) at fixed width?
* **Evidence**: by the determinant lemma $\det(A_0+G\Omega)=\det A_0\det(I_F+\Omega A_0^{-1}G)$ with $G=K[\mathrm{occ},:]H$, so the family is one $F\times F$ hidden-fermion factor; decoupled blocks share one $F$-dimensional readout space, so $F$ must grow with the number of blocks.
* **Why this kills it**: a fixed-size factor cannot multiply independent block corrections, the round-6 extensivity boundary condition.
* **What the kill does not rule out**: one hidden row per site with site-dependent readouts (R6.1′), which is size-consistent.
* **Strongest case against the kill**: none raised; it is an identity.
