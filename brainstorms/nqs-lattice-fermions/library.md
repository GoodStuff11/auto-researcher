## Index

* L1 (ESTABLISHED): On three $4\times3$ periodic Hubbard tori (widths 8–128, $P/d_{S\chi}\ge0.37$), 61–77% of the energy error of a neural backflow trained from a broken-symmetry UHF start is sign error; training inside the target sector removes over 99.999% of it, projecting afterwards only 1–90%.
* L2 (PROVISIONAL): For a symmetry-projected neural backflow on one $4\times4$ open $t$–$t'$–$J$ instance (widths 4–10), the sign error fell only with width (0.0192→0.0070) and no lower-energy better-signed state was found; a basin was never directly probed there, because no better-signed start was placed.
* L3 (ESTABLISHED): No function of Hamiltonian moments or of low-degree polynomial filters of the trial state can determine an observable error that sits in low-energy directions.
* L4 (PROVISIONAL): Excited-state subspace corrections are an exact-diagonalization diagnostic, not a scalable error bar: the window must hold every level carrying the observable error, which by level counting grows as $e^{sV}$ (the measured windows, at most 17.5 levels, do not by themselves show growth).
* L5 (PROVISIONAL): In the pair and charge channels of one $4\times4$ open $t$–$t'$–$J$ instance, the structure-factor error was 0–5% while the real-space long-range tail carried the error; rebuilding the pair tail from per-mode pieces needs about 0.5% per-mode precision (a cancellation ratio of about 100).
* L6 (ESTABLISHED): Certificates that divide by a spectral gap fail at competing-order points, where the gap closes: on a $4\times3$ torus crossing the Eckart bound certified 0 of 12 commits, and on a $4\times4$ state an oracle-energy window certificate was 8.6–81 times the true error.
* L7 (PROVISIONAL): Two macroscopically distinct orders share neither overlap nor local structure, so cross-order estimators cost samples exponential in the system size and shared-parameter error cancellation does not happen.
* L8 (PROVISIONAL): Ansätze that make the chemistry local energy cheap do so with configuration-independent or window-restricted orbitals, and they lose the external pair correlation that grows with the basis.
* L9 (PROVISIONAL): In linear H$_N$ chains ($N=6$–10, exact states), the kept fraction of plain screening falls with $N$ only in Boys-localized orbitals (0.31→0.08), against 0.85–0.91 in canonical orbitals; no estimator tested in canonical orbitals made it fall.
* L10 (PROVISIONAL): A correction with a fixed number of linear terms, Lanczos steps or symmetry-group elements gains $\mathcal O(1)$ to $\mathcal O(\sqrt V)$ energy against an $\mathcal O(V)$ error, so its relative gain vanishes with size.

* L12 (ESTABLISHED): Any single-proposal importance estimator of a non-stoquastic sum has a variance floor that does not vanish as the state converges.
* L13 (ESTABLISHED): Any first-order correction or dynamics built from the tangent space of a converged variational state vanishes, because the residual is orthogonal to that space.
* L14 (PROVISIONAL): A per-observable response vector recovers the observable error exactly at first order, but its tolerance to training error shrinks as the density of low-lying levels grows.
* L15 (PROVISIONAL): A Ritz correction built from noisy generated vectors cannot resolve a competitor closer than a noise floor, and a gap witness built from the same vectors over-estimates the gap.
* L16 (ESTABLISHED): Ritz diagonalisation in the span of two trained variational states returns the state with the lower trained energy, so it cannot beat their differential bias.
* L17 (PROVISIONAL): Any probe or transport of a trained, capacity-limited ansatz (field response, hysteresis, basin stability, continuation of trained snapshots) measures the biased energies, so it inherits the energy rule's decision boundary.
* L18 (PROVISIONAL): Parameter continuation from the non-interacting or sign-free limit follows the adiabatically connected branch and keeps the wrong state at near-degenerate level crossings.
* L19 (ESTABLISHED): In the infinite-sample limit the SR flow on a lattice is a function of expectation values, so sampler-only changes alter its noise but not its fixed points, and cannot target trained nodes.

## About the problem itself

### L1. On three $4\times3$ periodic Hubbard tori (widths 8–128, $P/d_{S\chi}\ge0.37$), 61–77% of the energy error of a neural backflow trained from a broken-symmetry UHF start is sign error; training inside the target sector removes over 99.999% of it, projecting afterwards only 1–90%.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic); restored after compaction per cross-node critic 2026-11-17
* **Applies to**: error budgets, basin studies or sign diagnostics of fermionic NQS trained from a symmetry-broken mean-field start (here unrestricted Hartree–Fock), and methods that restore symmetry after training.
* **The lesson**: A network trained from a broken-symmetry start mixes several symmetry sectors. Its error against the exact ground state is dominated by the wrong-sector admixture, much of which shows up as wrong signs, so its "sign errors" and "wrong-sign basins" are properties of the contamination, not of the nodes inside the target sector. Projecting afterwards never matched in-sector training: the in-sector part of the trained network is not the sector's best state; only training the projected network removes the error.
* **Evidence**: P1.1-P (job 407525): neural-network backflow (NNBF) of width 128 on three $4\times3$ periodic Hubbard tori ($5+5$ and $4+4$ at $U=8t$, $5+5$ at $U=4t$), medians over 3 seeds. The sign fraction $f_E=\Delta E_{\mathrm{sign}}/\Delta E_{\mathrm{tot}}$ ($\Delta E_{\mathrm{sign}}$: error of the best state with the network's signs) is 0.61–0.77 unprojected and at most 0.023 with space-group-projected training, which removes over 99.999% of the unprojected sign error (residual at most $3.5\times10^{-6}$ of it); post-hoc projection removes 35%, 90% and 1%, and exact spin projection alone leaves $f_E=0.37$, 0.67, 0.25. P1.3 R2.1 ($4+4$, $t'=-0.25t$): projected SR from the same UHF reaches $\Delta E_{\mathrm{sign}}\approx5\times10^{-6}t$ at width 8 against $0.082t$ unprojected at width 32, so an unprojected control would let a basin route "win" by symmetry restoration alone.
* **Scope and limits**: The three tori above (the wider networks fit the sector, L36), exact sums. Projected networks still carry sign error: $f_E=0.22$–0.24 on the $4\times4$ open $t$–$t'$–$J$ cluster (L2).
* **Counter-evidence and open questions**: Supersedes P1.1's PASS ("sign is the binding error", job 329057). Untested at sizes where projected training is too costly.
* **How to use it**: Train every control and arm inside the target sector before attributing error to signs or testing a basin-escape route; never substitute post-hoc projection.
* **Sources**: P1.1-P R1, R2 (job 407525); P1.1 R1 (job 329057, superseded); P1.3 R2.1; P4.1 RG5 (train unprojected, project at the end; killed as standard practice).

### L2. For a symmetry-projected neural backflow on one $4\times4$ open $t$–$t'$–$J$ instance (widths 4–10), the sign error fell only with width (0.0192→0.0070) and no lower-energy better-signed state was found; a basin was never directly probed there, because no better-signed start was placed.
* **Status**: PROVISIONAL
* **Applies to**: basin-escape, tempering, re-anchoring and second-order-optimiser proposals for fermionic NQS; any claim that a better optimiser would fix a trained network's signs.
* **The lesson**: If the residual sign error were a basin, a fit aimed at the exact signs would reach a markedly better-signed state and oracle-started runs would stay there. Neither happens. A second-order fit to a sign-oracle target (own amplitudes, exact signs) plateaus once its step is pure Gauss–Newton, so the plateau belongs to the family; oracle states with better signs sit higher in energy than the best cold run, so energy training rightly leaves them. At fixed width a better sign trades against amplitude accuracy; the sign error falls with width.
* **Evidence**: P1.3 R3.1 (jobs 507179, 625182; $4\times4$ open, $6+6$, $t'=-0.25t$, $J=0.4t$, 3 seeds per width): best cold $\Delta E_{\mathrm{sign}}$ 0.0192, 0.0117, 0.0070 at widths 4, 6, 10 (1284–2634 parameters); the released oracle arm ended at 0.0189, 0.0115, 0.0070 (margins 0.003–0.005); CAPACITY by the width tie-break. P1.3 R7.1 (projected $4\times3$ $t$–$J$ toy, $5+5$, 675 parameters, 3 seeds): the Levenberg–Marquardt sign-oracle fit got 22% below cold (0.00854 against 0.0093–0.0110), short of the 50% bar, with damping down to $10^{-10}$–$10^{-15}$; released, the states returned to cold. P1.3 R7.3 (gap $0.1217t$): 0 of 3 cold runs captured; the oracle state kept a better sign (0.0052 against 0.0084–0.0158) but sat $0.018t$ higher (one seed).
* **Scope and limits**: ED sizes, exact sums, projected arms. The claim rests on the $4\times4$ instance; the $4\times3$ toy ($P/d_{S\chi}=0.93$) measures sector fitting (L36). The tie-break is over unconverged runs (L33), and on $4\times4$ the oracle start was never better-signed than the best cold start (critic, Minor 8), so no basin was directly probed.
* **Counter-evidence and open questions**: Basins may appear at larger sizes or under sampling. The direct probe (P1.3 R7.7, about 250 CPU-h) was GATE-REFUSED (G2, $p\ge0.8$; G4); P1.3 is EXHAUSTED at this budget.
* **How to use it**: Spend effort on expressivity, not on basin escape or alternative optimisers for the sign; before a basin route, show a better-signed, lower-energy state that the same network reaches.
* **Sources**: P1.3 R3.1, R7.1, R7.2, R7.3, R7.5, R2.4; jobs 507179, 625182; master Revision Log (Minor 8).

### L3. No function of Hamiltonian moments or of low-degree polynomial filters of the trial state can determine an observable error that sits in low-energy directions.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic)
* **Applies to**: error bars on observables (correlation functions, order parameters) of any variational state, including variance extrapolation, Lanczos-step extrapolation, covariance regressions on energy moments and local imaginary-time steps.
* **The lesson**: Write the trial state as $\psi=\sum_nc_n\lvert n\rangle$ in eigenstates of $\hat H$ with excitation energies $\omega_n=E_n-E_0$. The error $\delta=\langle\psi\rvert\hat A\lvert\psi\rangle-\langle\psi_0\rvert\hat A\lvert\psi_0\rangle$ of an observable $\hat A$ depends on the signs of the $c_n$ and on the matrix elements of $\hat A$, while energy moments depend only on $\lvert c_n\rvert^2$ and $\omega_n$, so moments are blind to the sign of the error. A polynomial filter of degree $K$ in $\hat H$ with spectral width $W$ changes a component at excitation $\omega$ by at most about $2K^2\omega/W$, so it barely touches the low-energy components where a converged state's observable error sits (in a two-level model the Krylov vector $(\hat H-E)\psi$ reaches the competitor only with weight proportional to the gap $\Delta$).
* **Evidence**: P3.1 R1.1: on the real $4\times4$ state, one and two Lanczos steps cut the energy error from 0.052 to 0.023 and 0.015 while the pair-correlation error moved only from $2.9$ to $2.6$ and $2.8\times10^{-5}$. P3.1 R3.1: the ensemble covariance regressor reduces to the first Lanczos moment; pilot 410398 found 0 of 6 $4\times3$ instances with a target. R3.7, R5.4, R6.3 and R5.3 reduce to the same moments or filters by derivation.
* **Scope and limits**: Proven for moment functions and polynomial filters (P3.1 statements S1, S2). It does not cover rational filters: a shift-inverted residual escapes it (see L14 and L37). P3.1 R10.3 (a depth-2 Krylov two-mode window) is not counted as evidence: its $3\times3$ anchor is a 60-level sector nearly spanned by the method's subspace, a confounded toy (L40).
* **Counter-evidence and open questions**: None among the tested cases; the open question is whether shift-inverted, trained corrections keep their exact-arithmetic gain (P3.1 R10.1d, AMBIGUOUS).
* **How to use it**: Do not build observable error bars from energy variances, Lanczos steps or other polynomial filters; test any proposed estimator first on a two-level model with a near-degenerate competitor.
* **Sources**: P3.1 R1.1, R2.1, R3.1, R3.7, R5.3, R5.4, R6.3; job 410398; Sorella–Becca extrapolation (arXiv:cond-mat/0009149).

### L4. Excited-state subspace corrections are an exact-diagonalization diagnostic, not a scalable error bar: the window must hold every level carrying the observable error, which by level counting grows as $e^{sV}$ (the measured windows, at most 17.5 levels, do not by themselves show growth).
* **Status**: PROVISIONAL
* **Applies to**: excited-state Ritz corrections, observable-ordered windows and window-size extrapolations for long-range correlators in many-body variational methods.
* **The lesson**: A Ritz correction in a window of the $K$ lowest eigenstates fixes the observable error only if the window contains the levels that carry it. Define $K_{1/2}$ as the number of lowest in-sector levels needed to hold half of the error $\delta$. Because the number of levels below a fixed excitation energy grows as $e^{s V}$ with the number of sites $V$ (entropy density $s$), $K_{1/2}$ is expected to grow with size (an argument, not a measured trend), and ordering the window by observable weight instead of energy does not help. The error outside the window and the data inside it are different linear functionals, so no extrapolation in $K$ can recover the missing part.
* **Evidence**: P3.1 R7.1: median $K_{1/2}$ for the pair aggregate 2, 1, 2, 17.5 and for charge 1, 1, 2, 13 on toys of $3\times2$, $3\times3$, $6\times2$, $4\times3$; on the real $4\times4$ state $K_{1/2}$ is 2 (pair), 6 (spin), 11 (charge). P3.1 R8.4: observable-ordered windows moved median $K_{1/2}$ for spin from 1.5 to 9 and charge from 1 to 19. P3.1 R8.6: a counting argument shows that with more than $K+1$ out-of-window levels some perturbations change $\delta$ and leave every window datum unchanged.
* **Scope and limits**: Real-space long-range correlators. The median $K_{1/2}$ was at most 2 on $3\times2$, $3\times3$ and $6\times2$ toys and 13–17.5 on $4\times3$; on the real $4\times4$ state it was 2 (pair), 6 (spin), 11 (charge). Measured $K_{1/2}$ does not grow monotonically with $V$, so the size claim rests on the $e^{sV}$ level-count argument, and the toys' error weight was twice the real one. At exact-diagonalization size the method works (job 454376: 16 of 21 injected items, pilot 456094 GO), which is why it stays a diagnostic.
* **Counter-evidence and open questions**: Observables carried by one or two isolated low levels could escape the growth; none of the tested ones did.
* **How to use it**: Use excited-state windows only to diagnose where an error sits at exact-diagonalization size; check $K_{1/2}$ at two or more sizes before proposing a window method as an error bar.
* **Sources**: P3.1 R7.1, R8.4, R8.6; jobs 454376, 456094, 618646 (shelved extension).

### L5. In the pair and charge channels of one $4\times4$ open $t$–$t'$–$J$ instance, the structure-factor error was 0–5% while the real-space long-range tail carried the error; rebuilding the pair tail from per-mode pieces needs about 0.5% per-mode precision (a cancellation ratio of about 100).
* **Status**: PROVISIONAL
* **Applies to**: choosing target observables for NQS error estimation and toy tests; any method that reconstructs real-space correlations from momentum-resolved pieces.
* **The lesson**: A structure factor sums the correlation function over all distances, so short-range contributions that the network gets right dominate it, while the long-range tail that decides order is a small part of it. A method validated on structure factors can therefore look accurate where the error that matters is invisible, and assembling the tail from per-mode corrections requires per-mode precision about a hundred times finer than the tail error, because the modes cancel.
* **Evidence**: P3.1 R8.3 (job 698163, real $4\times4$ width-6 states, seeds 11, 22, 33): pair structure-factor errors 2.6%, 3.7%, 5.0% and charge 0.8%, 0.8%, 0.0%, while real-space long-range correlators carry the error (verdict NO-TARGET). P3.1 R8.9: the pair tail is about 1% of the structure-factor error ($2.75\,\delta$ against $1.0$–$2.0\times10^{-2}$), so factor-2 tracking of the tail needs per-mode precision of about 0.5%, a cancellation ratio of order 100.
* **Scope and limits**: One $4\times4$ open $t$–$t'$–$J$ instance (projected width-6 NNBF), three seeds; pair and charge channels only. The spin channel is outside the scope: there the structure-factor error was itself large ($-4.3\%$, $-13\%$, $-0.9\%$).
* **Counter-evidence and open questions**: None in the pair and charge channels. Another instance or size where the structure factor is wrong while the long-range tail is right would overturn it.
* **How to use it**: Measure the real-space long-range tail directly; never accept a toy result on a summed observable as evidence for the tail.
* **Sources**: P3.1 R8.3, R8.9; job 698163.

### L6. Certificates that divide by a spectral gap fail at competing-order points, where the gap closes: on a $4\times3$ torus crossing the Eckart bound certified 0 of 12 commits, and on a $4\times4$ state an oracle-energy window certificate was 8.6–81 times the true error.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic); restored after compaction per cross-node critic 2026-11-17
* **Applies to**: rigorous or semi-rigorous error certificates for variational states near phase competition: Temple, Weinstein and Eckart bounds, fidelity bounds, doublet and energy-window certificates, and curvature-based (Laplace or Fisher) posteriors.
* **The lesson**: Gap-based bounds divide by the gap to the next level (Temple needs a lower bound $\beta$ with $E<\beta\le E_1$; Eckart-type fidelity bounds scale as error over gap), and at a competing-order point that gap closes. Weinstein windows of width $2\sigma$ grow as $\sqrt V$ and hold exponentially many levels at finite energy density. Curvature posteriors give a small error bar when the family is stiff along the observable, which is when it cannot represent the competitor (compare L13).
* **Evidence**: P3.1 R7.3 (job 454376): even with oracle energies the energy-window certificate floor was 81 (pair), 8.6 (spin) and 29 (charge) times the actual error. P3.2 R5.1: on the 12-site torus crossing, Eckart commits only if the error ratio $\eta\le0.03$–0.08 (state error $\le4.6\times10^{-5}t$), while trained states had $\eta=0.19$–0.55 at width 8: 0 of 12 certified commits. P3.2 R5.2: the in-doublet rotation error scales as $\varepsilon/\Delta_1$. P3.1 R3.6: a curvature posterior on a stiff foil gives a small bar where the error is not small (derivation). P3.1 R1.2, R1.3, R6.5, R7.2 and P3.2 R1.3, R3.3 die on the same gap argument.
* **Scope and limits**: Arguments are general; measurements are from one $4\times4$ state (P3.1) and one $4\times3$ torus crossing (P3.2).
* **Counter-evidence and open questions**: With a robust gap the bounds are valid. Argued, not measured: susceptibility bounds need the true $\chi_A$, but a family that cannot represent the competing fluctuation is stiffer ($\hat\chi_A<\chi_A$) and reports a small error exactly when wrong; a pinning field gives a state with built-in order a linear response that extrapolates to its own order.
* **How to use it**: Do not propose a certificate for competing orders that divides by a gap or uses an in-family susceptibility; first check what it gives at a same-sector crossing.
* **Sources**: P3.1 R1.2, R1.3, R3.6, R6.5, R7.2, R7.3; P3.2 R1.3, R3.3, R5.1, R5.2; job 454376; Temple, Proc. R. Soc. A 119, 276 (1928); former anti-pattern "Bounds that need the gap"; L13.

### L7. Two macroscopically distinct orders share neither overlap nor local structure, so cross-order estimators cost samples exponential in the system size and shared-parameter error cancellation does not happen.
* **Status**: PROVISIONAL
* **Applies to**: deciding between competing orders with variational states: non-orthogonal configuration interaction (NOCI) between branches, ratio, mixture or correlated (paired) sampling of energy differences, curvature or susceptibility terms that need cross-order matrix elements, and shared-backflow or state-averaged ansätze meant to cancel errors.
* **The lesson**: Two states whose orders differ on an extensive region have overlap $\langle\psi_A\vert\psi_B\rangle$ and Bhattacharyya overlap $B=\sum_n\lvert\psi_A(n)\psi_B(n)\rvert$ that decay as $e^{-cV}$. Every sampled estimator of a cross-order quantity (ratio estimator, mixture sampling, paired sampling) has variance that grows as an inverse power of that overlap. The chemistry idea of making errors cancel by sharing parameters between compared species (isodesmic reactions) needs the two states to share local structure; distinct orders do not, so the bias stays differential.
* **Evidence**: P3.2 R1.4a and R7.2 (reopening-review T1, 12-site torus): $B\approx0.20$ already at 12 sites, and paired sampling cut the variance only by a factor 1.6 ($R_{\mathrm{pair}}\approx0.64$). P3.1 R3.3: seed NOCI needs cross-overlaps whose sampling cost is exponential in $V$. P3.2 R2.1 and R2.2: shared-backflow superposition and state-averaged two-reference backflow need heavy-tailed cross terms and are known ansätze. P3.2 R3.2: the curvature of a branch lacks the competitor term, because the competitor is outside the tangent space.
* **Scope and limits**: The decay is an argument for macroscopically distinct states; the only measurement is at 12 sites.
* **Counter-evidence and open questions**: For competitors that differ only locally (domain walls, few defects) the overlap does not decay and these estimators could work.
* **How to use it**: Before proposing any estimator that couples two competing branches, estimate how its variance scales with their overlap; expect only finite-size gains for distinct orders.
* **Sources**: P3.2 R1.4a, R2.1, R2.2, R3.2, R7.2; P3.1 R3.3; former master anti-pattern on non-orthogonal CI.

### L8. Ansätze that make the chemistry local energy cheap do so with configuration-independent or window-restricted orbitals, and they lose the external pair correlation that grows with the basis.
* **Status**: PROVISIONAL
* **Applies to**: neural or Jastrow-type ansätze for second-quantized molecular Hamiltonians whose local energy is made contractible or cheap by freezing orbitals, restricting the backflow input to an orbital window of size $K$, or coarse-graining the input.
* **The lesson**: In a molecular basis, energy optimisation puts the multireference correlation into the configuration dependence of the orbitals. A surrogate with configuration-frozen orbitals discards it, so its residual stays of order one; a backflow that sees only an active window is a single determinant in the external orbitals and misses the external pair correlation, which dominates the correlation energy as the basis grows. Removing external–external Jastrow pairs costs nothing measurable, which locates the binding limit in the frozen orbitals, not the Jastrow.
* **Evidence**: P2.2 R1.4: frozen-backflow control variate residual fraction 0.56–0.82 on H$_4$ and 0.69–0.80 on H$_6$ (STO-3G, $R=3.0$ bohr); cost ratio $M=1.03$–$1.07$ against the best control. P2.2 R4.1 (pilot 411919, distorted H$_4$ at $R=4.4$ bohr, $K=20$, 3 seeds): median error 0.691 mHa against the 0.2 mHa target. P2.2 R5.1 (job 452238): WIBJ error 0.013, 0.064, 0.187 mHa at $K=12$, 16, 20 against NNBF-Jastrow's 0.028 mHa, extrapolating to 0.61–7.3 mHa at $K=40$. P2.2 R6.1: contractible CAS×Jastrow 0.3885 mHa with external pairs masked against 0.3899 unmasked (H$_4$, $K=12$). P2.2 R2.6 by argument.
* **Scope and limits**: Hydrogen chains and rings, H$_4$ to H$_8$, STO-3G and small bases up to $K=136$ for cost, $K\le20$ for accuracy.
* **Counter-evidence and open questions**: A window that grows with the basis at sub-cubic cost was not found; it would overturn the lesson.
* **How to use it**: For a cheap-local-energy ansatz with frozen or window-restricted orbitals (tested here on one molecule family, hydrogen chains and rings, at $K\le20$ spatial orbitals), measure its own absolute error as the basis grows at fixed geometry, against a minimal-contrast foil; if the error rises with $K$ while the foil's does not, the restriction is discarding the external pair correlation, and the lever is the orbital freedom, not the Jastrow.
* **Sources**: P2.2 R1.4, R2.6, R4.1, R5.1, R6.1; jobs 411919, 452238.

### L9. In linear H$_N$ chains ($N=6$–10, exact states), the kept fraction of plain screening falls with $N$ only in Boys-localized orbitals (0.31→0.08), against 0.85–0.91 in canonical orbitals; no estimator tested in canonical orbitals made it fall.
* **Status**: PROVISIONAL
* **Applies to**: screening, truncation and certified-screening schemes for local energies of second-quantized chemistry NQS.
* **The lesson**: In canonical (delocalized) orbitals almost every connected term of the local energy is non-negligible, so screening keeps most of them at any system size. P2.2 R7.1: a certified variational screen in canonical orbitals keeps 0.917, 0.949, 0.976 at the same sizes.

* **Counter-evidence and open questions**: Certifying the saving in localized orbitals is cheap only with a precomputed global compensator. In Löwdin orbitals the best kept-pair compensator certifies 0.44 (H$_6$) and 0.42 (H$_8$) times plain screening's kept fraction and is admissible on states trained to $\Delta E\le0.03$ mHa; at the leaf's working accuracy ($\approx0.74$ mHa) H$_8$ excess reached 9–16$\tau$, but evaluating it needs reference amplitudes on about 1352 of 4900 determinants per sample at H$_8$; any practical reference either costs more than exact enumeration or breaks the bound (P2.2 R7.4, KILLED at T0 on cost; L27).

### L10. A correction with a fixed number of linear terms, Lanczos steps or symmetry-group elements gains $\mathcal O(1)$ to $\mathcal O(\sqrt V)$ energy against an $\mathcal O(V)$ error, so its relative gain vanishes with size.
* **Status**: PROVISIONAL
* **Applies to**: corrections for extensive systems that add a fixed number $K$ of linear terms: linear dressings $(1+\sum_b\alpha_b\hat K_b)\Phi$, fixed-rank sums of mean-field states or determinants, mixtures of experts, fixed numbers of Lanczos or power steps, linear corrections in fixed global vectors, and projection onto a fixed group.
* **The lesson**: A variational state's error on $V$ sites is of order $V$. Components that differ on an extensive region are exponentially orthogonal, so a fixed linear superposition gains $\mathcal O(1)$, at most $\mathcal O(\sqrt V)$; a fixed number of Lanczos steps gains about $\sqrt{\kappa_2}\propto\sqrt V$ ($\kappa_2$ the extensive energy variance); fixed-group projection restores symmetry at $\mathcal O(1)$. The relative gain vanishes as $V$ grows. Block-parity signs are a separate obstruction (L53).
* **Evidence**: P4.1 R1 (job 508440): on a 12-site open cluster a rank-8 exact-spin mixture beat the single component `che` 2.5-fold ($1.35$ against $3.43\times10^{-4}$), but the T0 argument gives $\epsilon_K/\epsilon_{\mathrm{che}}\to1$ with size, and the VMC pilot projected 0.64–0.82 at 48 sites (killed at Gate 4). P3.1 R10.1: in a toy of $M$ decoupled copies a fixed-base response correction recovered 0.95→0.81 and 0.91→0.53 of the error as infidelity grew, against 0.99–1.01 with the base updated. P3.2 R7.1: one Lanczos step gains $\propto\sqrt V$ against bias $\propto V$. P1.2 R2.3, R7.5, P2.2 R7.2, P3.1 R10.2, P4.1 R2.1, R5, R9, R12, RG1, RG2, P4.2 R9.7 and P2.1 R6.3 die on the same argument.
* **Scope and limits**: T0 arguments plus Becca–Sorella; the one measurement (12 sites) is consistent; no size ladder was run. Says nothing against such corrections at a fixed small size.
* **Counter-evidence and open questions**: None measured; ESTABLISHED needs a measured size trend (P4.1 R1's ladder, job 686990, was cancelled).
* **How to use it**: Run Gate 4 by argument first: does the number of terms, steps or group elements grow with $V$? If not, expect only a finite-size gain.
* **Sources**: P1.2 R2.3, R7.5; P2.1 R6.3; P2.2 R7.2; P3.1 R10.1, R10.2; P3.2 R7.1; P4.1 R1, R2.1, R5, R9, R12, RG1, RG2; P4.2 R9.7; job 508440; Becca et al., arXiv:1412.2656. Split 2026-11-17: block parity to L53, projector step (P1.3 R1) to L21, P3.2 R6.5 to L42, P4.1 R4 to L11.

### L53. A sum of $K$ low-degree terms, or a fixed-size factor shared by all blocks, cannot represent a sign that is the parity of $M$ independent blocks once $M$ exceeds its degree; independent block corrections need a product inside one determinant or Gaussian.
* **Status**: PROVISIONAL
* **Applies to**: shared-reference low-rank sums of determinants or pairing states, global-kernel or global-summary readouts that feed one fixed-size factor to every region, and products of local ratio factors proposed to make a sign correction size-consistent.
* **The lesson**: A wave function on $M$ decoupled blocks whose sign errors are independent needs a correction whose sign is the product (parity) of $M$ block signs. Parity has polynomial-threshold degree $M$, so a sum of $K$ terms of low degree, or one fixed-size factor shared by all blocks, cannot represent it once $M$ exceeds that degree. The size-consistent form is a product over blocks, and it must live inside one object: multiplying normalised ratio factors that share one reference determinant divides by that reference once per factor, which creates a pole of order $V-1$ at its nodes.
* **Evidence**: P2.1 R3.1 and R3.2 (shared-reference low-rank sums, parity lemma at T0; the earlier decisive array 526080 had found only finite-size gains, AMBIGUOUS). P2.1 R6.1 (one fixed $F\times F$ hidden-fermion factor for all regions) and R7.4 (a linear-attention global summary feeding a fixed-rank factor), killed at Gate 4 by the same argument. P2.1 R6.2 (product of rank-1 ratio factors on one reference): $\lvert\psi\rvert\propto\varepsilon^{-35.11}$ near reference nodes at $M=V=36$ (predicted $\varepsilon^{-35}$), local energy near $-9\times10^{20}$ at $L=8$, which is why the product must sit inside one determinant or Gaussian.
* **Scope and limits**: T0 arguments plus one pole measurement; no route with the product inside one object was built and tested here, so the positive half is an argument.
* **Counter-evidence and open questions**: None measured. Whether a product inside one determinant (for example block-structured orbitals) keeps its gain at a cost that does not grow faster than the foil's is open.
* **How to use it**: Before proposing a sum or a shared factor as a sign correction, count its degree against the number of independent blocks at the target size; if a product is needed, put it inside one determinant or Gaussian, never as a product of ratios over a shared reference.
* **Sources**: P2.1 R3.1, R3.2, R6.1, R6.2, R7.4; job 526080. Split from L10 on 2026-11-17 (cross-node critic).

### L11. Exact SU(2) projection at polynomial cost was obtained only when every spin-breaking ingredient sat inside a Gaussian; any spin-diagonal factor makes the rotated amplitude an exponential orbit sum (Lemma B).
* **Status**: ESTABLISHED (2026-11-17, cross-node critic; restored after compaction; outside-the-class scope added 2026-11-17, P4.1 round 30)
* **Applies to**: exact SU(2) or other non-Abelian projections of neural or correlated fermion states.
* **The lesson**: Spin projection integrates the state over the group. If the spin-breaking part is a Gaussian (determinant or pairing state) per charge configuration, the rotated Gaussian is closed-form and polynomially many quadrature nodes suffice. Any diagonal factor that reads the broken quantity (spin Jastrow, spin-resolved network, spin features, plaquette exchange) makes the rotated amplitude a sum over an exponential orbit. Sampling it trades cost for variance: the kernel's absolute sum grows as $(\lvert\cos\tfrac\beta2\rvert+\lvert\sin\tfrac\beta2\rvert)^{N_s}$, so the average sign decays as $e^{-a\sqrt{N_s}}$ ($N_s$ spins). A product of per-patch sums does not escape: rank 1 collapses to one determinant; rank $\ge2$ gives a sum over exponentially many block-structured determinants, like a #P-hard mixed discriminant (no polynomial resummation known).
* **Evidence**: (all P4.1) R0.2: projecting a spin-resolved NNBF sums $\binom{N_s}{N_s/2+M}$ signed terms. R2.4: numerator-only sampling, average sign $e^{-a\sqrt{N_s}}$. R10: a size-extensive spin Jastrow needs $2^{\#\mathrm{bonds}}$ Hubbard–Stratonovich fields. R3.2, R4.3, R5.1, R5.3, R5.7, R13 fail the same way (Gate 1). The closed-form class (charge-backflowed Gaussians: `che`, `pcg`) projects exactly ($\langle S^2\rangle\sim10^{-16}$). R4: the patch product collapses or needs the exponential sum (T0). R25 (T0): an SU(2)-scalar bond decoupling is exact per field, but its sampled phase decays exponentially in the bond count.
* **Scope and limits**: Proven for SU(2) on Hubbard-type models; the closed-form class is not shown accurate enough (P4.1, R2). Outside the class (exact without a Gaussian): non-diagonal SU(2)-scalar operators (P4.1 R12, R13, R2.1, R25) and spin-adapted bases (R0.4, R22), none killed for inexactness (scaling: R12, R2.1; exponential cost or noise: R13, R25; accuracy: R22; novelty: R0.4).
* **Counter-evidence and open questions**: None among the tested constructions; a closed-form group-covariant object beyond Gaussians would extend the class.
* **How to use it**: Before an exact-symmetry ansatz, check that every symmetry-breaking ingredient sits in a group-covariant object with closed-form rotation; else count the orbit sum at T0 and stop.
* **Sources**: P4.1 cards above (Lemma B in the P4.1 leaf); L56.

### L12. Any single-proposal importance estimator of a non-stoquastic sum has a variance floor that does not vanish as the state converges.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic)
* **Applies to**: stochastic local energies (heat-bath, semistochastic, factorized-Hamiltonian proposals), stochastic determinant-ratio estimators and doubly stochastic SR forces for fermionic NQS.
* **The lesson**: Estimating $\sum_jx_j$ with one importance distribution has per-draw variance at least $(\sum_j\lvert x_j\rvert)^2-(\sum_jx_j)^2$, which is non-zero whenever the terms have mixed signs, as in non-stoquastic fermionic Hamiltonians, and does not shrink as the state converges (unlike the exact local energy, whose variance vanishes at an eigenstate). Non-linear use of the estimate (ratios, the inverse SR metric) adds bias and amplifies the noise. On a converged H$_6$ state the oracle proposal already cost 146× exact enumeration. Multi-proposal or sign-stratified schemes are not covered, but they did not help where magnitude errors dominate (P2.2 R2.1).
* **Evidence**: P2.2 R1.1 (H$_6$ chain, STO-3G, $R=3.0$ bohr, state 0.17 mHa from the ground state): heat-bath costs $657\times$ exact enumeration; semistochastic $0.932\times$ against plain screening $0.911\times$. P2.2 R1.3: even the oracle proposal $p\propto\lvert x\rvert$ costs $145.6\times$ exact. P2.2 R1.2: the SR force noise is amplified by $S^{-1}$ along small-eigenvalue directions. P2.1 R4: an unbiased signed Russian-roulette ratio series has variance diverging near nodes.
* **Scope and limits**: Small molecules (H$_4$, H$_6$) for measurements; the floor itself is a general inequality.
* **Counter-evidence and open questions**: None measured.
* **How to use it**: Compare any stochastic local energy against exact enumeration with screening at a converged state, not at a poor one; prefer deterministic reductions of the number of terms.
* **Sources**: P2.2 R1.1, R1.2, R1.3; P2.1 R4; former master global anti-pattern "Single-proposal stochastic replacement of an exact non-stoquastic sum"; semistochastic NQS local energies (arXiv:2507.19276).

### L13. Any first-order correction or dynamics built from the tangent space of a converged variational state vanishes, because the residual is orthogonal to that space.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic)
* **Applies to**: error bars from tangent-space Ritz (linear method at convergence), in-family zero-bias corrections, time-dependent variational dynamics and eigenvector continuation of nearby trained states.
* **The lesson**: At a converged variational minimum the residual $r=(\hat H-E)\psi$ is orthogonal to every tangent vector $\partial_k\psi$ (Brillouin condition), so any correction expanded in the tangent span gives zero, the tangent Ritz vector is $\psi$ itself, and the projected (TDVP) dynamics has $\psi$ as a fixed point. Corrections from nearby trained states (field ladders) differ from $\psi$ by tangent vectors to first order and share its bias at finite field. Curvature-based (Laplace or Fisher) posteriors are a different failure: they do not vanish, but they are small where the family is stiff (L6).
* **Evidence**: P3.1 R3.4 (lemma, Round 3), R7.4, R7.5, R8.2 (derivations).
* **Scope and limits**: Exact for converged states; an unconverged state leaves a non-zero but uninformative remainder.
* **Counter-evidence and open questions**: None.
* **How to use it**: Reject any error estimator that only uses the trained state's own tangent space or dynamics; information must come from outside the family (an exact or trained shift-invert, a different family).
* **Sources**: P3.1 R3.4, R7.4, R7.5, R8.2; Frame et al., PRL 121, 032501 (2018). Cross-link: L6 (posteriors, moved there on 2026-11-17).

### L14. A per-observable response vector recovers the observable error exactly at first order, but its tolerance to training error shrinks as the density of low-lying levels grows.
* **Status**: PROVISIONAL
* **Applies to**: zero-bias corrections with trained improved functions (Assaraf–Caffarel type), response-window Ritz methods and shift-inverted responses for observable error bars.
* **The lesson**: The response $\lvert\chi\rangle=(\hat H-E_0)^{-1}Q(\hat A-a)\psi$, with $Q$ the projector off $\psi$, gives the first-order error of $\langle\hat A\rangle$ exactly. Built with a trained network, it enters a Ritz problem whose denominator is its energy-weighted norm, which is dominated by low-lying levels; as their density grows, a fixed relative training error in $\chi$ moves the correction by more, so tracking falls with size.
* **Evidence**: P3.1 R8.1: response-window Ritz with noisy responses tracked (estimate within a factor 2 of the true error) 0.80 of items at $3\times2$ and 0.37 at $4\times3$. P3.1 R8.8: 0.86 at $3\times2$ and 0.33 at $4\times3$ on structure factors. P3.1 R9.1: Krylov-cleaned responses 0.91 at $3\times3$ and 0.56 at $4\times3$. P3.1 R3.2: the first-order oracle over-stated the error by 1.5–2.2 at infidelities 0.02–0.2. With exact responses the method recovered 8 of 8 real $4\times4$ items (699756), and trained responses tracked 9 of 11 items on a $4\times3$ T3 (705951).
* **Scope and limits**: Toys up to 12 sites, noise models for training error; the exact-response success is an inverse-iteration premise (L37). The R9.1 drop from $3\times3$ uses a confounded anchor (L40). At T1b with the real error weight, tracking was 0.65 and 0.67 at $6\times2$ and $4\times3$.
* **Counter-evidence and open questions**: The self-consistent version (P3.1 R10.1d) is AMBIGUOUS: trained responses 9 of 11, a twice-wider network 7 of 10.
* **How to use it**: Test any response-based error bar at two or more toy sizes with the realistic training-error level, and compare with a matched capacity foil (L38).
* **Sources**: P3.1 R3.2, R8.1, R8.8, R9.1, R10.1d; jobs 699756, 705951.

### L15. A Ritz correction built from noisy generated vectors cannot resolve a competitor closer than a noise floor, and a gap witness built from the same vectors over-estimates the gap.
* **Status**: PROVISIONAL
* **Applies to**: Davidson-type or observable-sourced Ritz corrections and gap witnesses built from sampled or trained vectors.
* **The lesson**: Each generated vector carries a noise of relative size $\eta$ spread over levels at typical excitation $\bar\omega_w$. In the Ritz problem that noise acts like a level shift of order $\eta^2\bar\omega_w$ divided by the coherent weight $w_c$ the sources put on the competitor. A competitor closer than that floor is mixed away, and the Ritz gap between the two lowest Ritz values reports the floor, not the true gap, so a certificate that "the gap is large" is false exactly when the gap is small.
* **Evidence**: P3.1 R10.4 (observable-free generalised Davidson with grade-R noise): native gaps tracked 1.00, 1.00, 0.80 at $4\times2$, $5\times2$, $4\times3$, but with a competitor moved to $0.02t$ (stress) only 0.00, 0.12, 0.18; noise-free it tracked 1.00. P3.1 R12.1: at stress $\Delta=0.02t$ the witness gap was $0.41t$ and $0.47t$ (twenty times the true gap), with false-certificate rates 0.88 and 0.71; the Davidson-sourced witness fails identically.
* **Scope and limits**: Toys of 8 to 12 sites with a modelled noise grade.
* **Counter-evidence and open questions**: An interval readout (P3.1 R12.3d, live) is designed to stay honest below the floor; it is untested.
* **How to use it**: Report any Ritz-based error bar with its noise floor $\eta^2\bar\omega_w/w_c$, and test it with an artificial competitor moved below that floor.
* **Sources**: P3.1 R10.4, R12.1, R12.3d.

### L16. Ritz diagonalisation in the span of two trained variational states returns the state with the lower trained energy, so it cannot beat their differential bias.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic)
* **Applies to**: decisions between competing orders from trained variational states: excited-state Ritz with a penalty-trained partner, Ritz in the span of two order branches, jointly optimised two-state ensembles relabelled by character.
* **The lesson**: For a real symmetric $2\times2$ matrix the lowest eigenvector has weight at least $\tfrac12$ on the basis vector with the lower diagonal entry, whatever the coupling. So a Ritz rotation of two trained states decides like the energy rule between them: it picks the state whose trained energy $E_X+b_X$ (true energy plus variational bias $b_X$) is lower, and is wrong whenever the differential bias $\Delta b$ exceeds the true gap $\delta$. Off-diagonal information can change this only through the coupling $W$, which is bounded by about half the smallest gap.
* **Evidence**: P3.2 R6.1 (job 619080, 84 CPU-h, width 4, 9 instances on a $4\times3$ Hubbard torus with a same-sector crossing): the Ritz decision equalled the lower-diagonal prediction on 9 of 9 and was right on 4 of 9; diabatic coupling $W\approx5\times10^{-4}t$ against measured $\Delta b=3.6$–$5.4\times10^{-3}t$. P3.2 R6.2 and R6.3: the same lemma for the residual-augmented and two-branch spans. P3.2 R1.4: the jointly optimised ensemble relabelled by character reduces to the same rule. P3.1 R7.7: multi-seed Ritz inherits the seeds' shared bias.
* **Scope and limits**: One 12-site torus crossing between spin textures forced by $L_y=3$, widths 4 and 8; the lemma itself is general. The lemma assumes nearly orthogonal branches, as distinct orders are (L7).
* **Counter-evidence and open questions**: A symmetric block-Lanczos step with exact matrices escapes it (9 of 9 in-sample), but that is the exact Hamiltonian at work (L37), and sampled, it abstains (L45).
* **How to use it**: Do not expect a Ritz rotation of trained states to decide better than comparing their energies; use the plain energy rule with honest abstention.
* **Sources**: P3.2 R1.4, R6.1, R6.2, R6.3; P3.1 R7.7; job 619080. Cross-link: L17.

### L17. Any probe or transport of a trained, capacity-limited ansatz (field response, hysteresis, basin stability, continuation of trained snapshots) measures the biased energies, so it inherits the energy rule's decision boundary.
* **Status**: PROVISIONAL
* **Applies to**: deciding competing orders with variational methods by conjugate fields, level-crossing kinks, Berry phases in parameter space, branch-stability kicks, eigenvector continuation or affine transport of snapshots.
* **The lesson**: A capacity-limited ansatz in branch $X$ has energy $E_X+b_X$, with $b_X$ its variational bias. Every functional of its landscape (where branches cross under a field, which basin survives a kick, where the lower envelope has a kink, where the Berry phase sees a seam) is a functional of those biased energies, so it puts the decision boundary at $\delta+\Delta b=0$ (true gap $\delta=E_A-E_B$, differential bias $\Delta b=b_A-b_B$), the same boundary as comparing energies. Transporting trained states from where training is easy to where the decision is hard removes optimisation failure at the target but carries the snapshots' differential bias with it. Affine transport adds its own bias even from exact snapshots.
* **Evidence**: P3.2 R3.5 (job 451852, 1,412 CPU-h): same-order eigenvector continuation at width 4 (676 parameters) committed on all 15 hard (target, seed) pairs and was wrong on 5 (wrong-commit rate 0.33), always toward order $A$ on the $B$ side, while oracle continuation from exact snapshots was right everywhere. Separately, affine transport adds its own bias even from exact snapshots: in P3.2 R3.6 it commits the wrong order at $d=-0.0002$ because the diabats' curvatures differ ($-14$ against $-10$), a transport bias of $2.1\times10^{-3}t$ above the $1.4\times10^{-3}t$ gap. P3.2 R2.3, R2.7, R3.1 and R7.4 by argument.
* **Scope and limits**: One $4\times3$ torus crossing; widths 4 and 8.
* **Counter-evidence and open questions**: None among tests; a probe that uses information outside the family (exact $\hat H$ action) is not covered.
* **How to use it**: Before proposing a landscape probe, write its decision boundary in terms of $E_X+b_X$; if it is $\delta+\Delta b=0$, it is the energy rule in disguise.
* **Sources**: P3.2 R2.3, R2.7, R3.1, R3.5, R3.6, R7.4; job 451852. Cross-link: L16.

### L18. Parameter continuation from the non-interacting or sign-free limit follows the adiabatically connected branch and keeps the wrong state at near-degenerate level crossings.

### L19. In the infinite-sample limit the SR flow on a lattice is a function of expectation values, so sampler-only changes alter its noise but not its fixed points, and cannot target trained nodes.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic)
* **Applies to**: sign-flip-aware Metropolis moves, node-targeted or importance-modified sampling, and other sampler changes proposed to fix the trained nodes of a lattice NQS.
* **The lesson**: On a lattice, Metropolis sampling of $\lvert\psi\rvert^2$ jumps between configurations and never visits the zero-amplitude points between them, so nodes do not confine it (unlike continuum diffusion). The SR update is a function of expectation values, so in the infinite-sample limit its fixed points do not depend on the sampler; a sampler change alters only the noise, not the flow.
* **Evidence**: P1.3 R3 and P1.2 R6.6 (arguments); every decisive test in P1.2 and P1.3 used exact sums, where no sampler enters, and still found the same trained nodes.
* **Scope and limits**: Exact-expectation optimisers; at finite samples a sampler changes noise and can change stochastic trajectories, but not the targeted fixed points.
* **Counter-evidence and open questions**: None.
* **How to use it**: Fix trained nodes through the ansatz or the objective, not the sampler.
* **Sources**: P1.3 R3; P1.2 R6.6.

### L29. In linear-method or natural-gradient steps for over-parameterised states, truncate the parameter metric instead of shifting it, and choose the cutoff per step from a ladder by the exact or held-out energy, because a fixed relative cutoff can freeze the step.

* **The lesson**: In an over-parameterised state the metric $S$ has a long tail of tiny eigenvalues and part of the linear-method gain lies along them; an unregularised $S^{-1}$ turns it into huge steps, and a level shift large enough to tame them also kills the gain. Symmetrising loses the zero-variance property (the sampled eigenproblem is exact for any sample when the tangent space holds an eigenstate), so at few samples per parameter the step follows the noise. The non-symmetric estimator removes the catastrophe, but at realistic sample counts noise in the low-eigenvalue directions, where the gain sits (L29), still dominates.
* **Evidence**: P4.1, open $4\times3$ Hubbard, $5+5$, $U=8$, $t'=-0.25$, `che` state (2637 parameters), cutoff $10^{-5}$, exact scoring. Symmetrised, 8192 fresh samples per step (about 3 per parameter), job 731462: the exact energy rose on all 4 steps ($R=-4.9$, $-14.1$, $-24.0$, $-42.4$ gaps) while in-sample estimates claimed drops. Non-symmetric one-step probes (`tests/P4.1_cheap_su2_r20/results_probe`): at 8192 samples every candidate raised the exact energy by 0.16–0.78 gaps (fresh-sample validation rejected all); at 65,536 (about 25 per parameter) the best gained $R=0.080$ against 0.269 exact (about 30%), rated 1.8σ by validation and rejected. The 4-step follow-up was refused by the gate (G2, NOT-VIABLE or MARGINAL at up to 8 samples per parameter, $p=0.9$).
* **Scope and limits**: One 12-site state, one seed; non-symmetric results are one-step probes; blocked or reduced-rank variants and other NQS untested.
* **Counter-evidence and open questions**: Sampled linear methods work in quantum-chemistry VMC with tens to hundreds of parameters and many samples each; where the crossover lies for NQS, and whether a reduced-block LM or minSR avoids it, is open.
* **How to use it**: Use the non-symmetric estimator, validate every step on fresh samples, report samples per parameter, and check on a small exact instance that the sampled step keeps at least half the exact gain before a large-system rung.
* **Sources**: P4.1 R18″, job 731462; `tests/P4.1_cheap_su2_r19/`, `tests/P4.1_cheap_su2_r20/`; L29, L52; Toulouse & Umrigar, J. Chem. Phys. 126, 084102 (2007).

### L56. Frame averaging and canonicalisation make a network exactly invariant at small cost only when the group maps inputs to inputs; SU(2) acting on Fock-basis amplitudes superposes basis states, so the only cheap frame is the spin-flip subgroup, which gives a parity, not a total spin.
* **Status**: PROVISIONAL
* **Applies to**: imposing a continuous non-Abelian symmetry on a lattice wave function or quantum-state network by averaging over a finite subgroup, a frame or a canonical orientation.
* **The lesson**: In machine learning a group average is cheap because each element maps inputs to inputs, one forward pass per term. In an occupation basis a spin rotation acts on the state: a rotated configuration superposes all spin arrangements on its singly occupied sites. Only the $\pi$ rotations (spin flips with phases) cost one evaluation; every other element costs an orbit sum over $\binom{N_s}{N_s/2}$ arrangements for a network that reads spins. A finite subgroup also leaves spin $S'\ge4$ components (octahedral group), and filtering them with a polynomial in $\hat S^2$ needs a number of factors that grows with $N_s$. The cheap part delivers a parity; the exact part is exponential.
* **Evidence**: P4.1 R23 (T0): averaging over the binary octahedral group $2O$ (48 elements) leaves the trivial irrep in $S'=0,4,6,8,9,\dots$; only spin flips have one-term matrix elements, every other element is an orbit sum (Lemma B). P4.1 R24 (T0, its translation repair): spin-flip averaging plus a Löwdin filter needs about $N_s/4$ factors, each connecting a configuration to $\mathcal O(N_s^2)$ others, so cost $N_s^{\mathcal O(N_s)}$; truncating the filter is the killed R5.2.
* **Scope and limits**: Arguments, not measurements; $S^z$ occupation basis; networks that read spins. Point-group averaging (which permutes configurations) and spin-adapted bases (P4.1 R22) are not covered.
* **Counter-evidence and open questions**: High-spin admixtures may carry negligible weight on low-energy states, so an approximate frame average might help where exactness is not needed; untested.
* **How to use it**: Before porting an equivariance technique, check whether the group permutes the network's inputs in the chosen basis; if it superposes them, the options are a Gaussian-closed projection (L11) or a change of basis.
* **Sources**: P4.1 R23, R24 (Round 20); Puny et al., arXiv:2110.03336; Kaba et al., arXiv:2211.06489; L10, L11.

### L57. Analogies that make long-range structure cheap by exploiting decay or smoothness (domain-local correlation, fast-multipole far fields) do not carry over to an error that sits in non-local nodal structure; making the far part affordable forces it back into a known low-rank restriction.
* **Status**: PROVISIONAL
* **Applies to**: cost reductions of neural backflow, hidden-fermion or other ansätze whose binding error is sign or nodal structure, by locality, domain truncation, or hierarchical or low-rank far fields.
* **The lesson**: Local correlation and fast-multipole or hierarchical-matrix methods work because what they truncate decays (dynamic correlation in gapped systems) or is smooth (far-field kernels). In a fermionic NQS the part that must be kept, the configuration dependence that corrects the reference's nodes, is non-local. A domain-local coupling turns the ansatz into finite-range backflow, whose known accuracy gap is the barrier; a far field restores long range only at a rank where the cost advantage survives, which is the published low-rank restriction with its expressivity loss.
* **Evidence**: P2.1 R15.4 (G0): domain-local hidden couplings give finite-range backflow (SCALE, arXiv:2604.25775; tensor backflow, arXiv:2407.11779), whose gap of 3–$4\times10^{-3}t$ per site at $16\times16$ is the leaf's barrier, although its operation count passed the cost bar about 14-fold. P2.1 R15.5 (its translation repair): near plus cluster-basis far field costs $8.6\times10^7$ multiply-adds per sweep at far rank $V/8$ (1.57 times cheaper than R13.1) but $1.27\times10^8$ at $V/4$ (1.06 times), because the far part enters every ratio; the affordable rank is where Liu and Clark (arXiv:2311.09450) show corrections are less expressive than full backflow. Earlier: P2.1 R2.6 (fast-multipole backflow with a linear-pooling far field).
* **Scope and limits**: Gate-level arguments with operation counts on one engine; no accuracy measurement of the near-plus-far family; one leaf.
* **Counter-evidence and open questions**: R15.5's near field is full rank and patch-nonlinear, so the family is not exactly tensor backflow; a kill-only accuracy test at 12 and 15 sites (about 30 CPU-minutes) and per-configuration far ranks were not tried.
* **How to use it**: Before importing a locality or far-field compression, ask whether the error to keep decays or is smooth; if it is nodal, expect a known truncated family and check its published expressivity barrier before costing it.
* **Sources**: P2.1 R15.4, R15.5, R2.6; Pulay, Chem. Phys. Lett. 100, 151 (1983); Riplinger & Neese, J. Chem. Phys. 138, 034106 (2013); Greengard & Rokhlin, J. Comput. Phys. 73, 325 (1987); Hackbusch, Computing 62, 89 (1999).

### L58. In patch-local hidden-row (hidden-fermion) families, a hop changes every hidden row whose receptive field contains a touched site, so thinning the rows while widening their receptive fields restores the update rank of the all-rows family and saves only the matrix dimension.
* **Status**: PROVISIONAL
* **Applies to**: cost design of hidden-fermion determinant or pairing states with local feature patches, and of any low-rank-update ansatz whose rows depend on local neighbourhoods.
* **The lesson**: The cost of an accepted move in a carried-inverse engine is set by the update rank $k$, the number of matrix rows a hop changes, times the square of the carried dimension $n$. A hidden row changes when any site in its receptive field changes, so $k$ is the number of row centres within the receptive-field radius of the touched sites. Removing rows (a sublattice) lowers $k$ and $n$ together, but it also removes the features of the missing centres; widening the remaining rows' receptive fields to recover those features brings $k$ back to the all-rows value, and only the $n^2$ saving remains.
* **Evidence**: P2.1, square lattice, 8b proposal (nearest-neighbour and diagonal hops equally likely). Counted: plus-patch checkerboard `half` $b=4.0$ (measured 4.0 in Round 12c), plus-patch all-sites `full` $b=8$ (measured $k=9.6$), radius-2 `half` $b=9.0$, so $k\approx9.8$, the same as `full` (R15.2, T0, 2026-11-17); its predicted $R_D(16)$ of 3.3–4.2 is no better than the measured $3.50\pm0.85$ of the all-sites Schur engine (R13.1). Learned per-configuration gating at half activity (R15.6, T1) measured 3.81 rows changed plus 1.75 gate flips per accepted hop, consistent with the same count.
* **Scope and limits**: Square lattice, plus-shaped and radius-2 patches, one proposal; costs from two-term models fitted to measured $L=16$ timings; not tested on GPU or batched engines, where kernel speeds differ.
* **Counter-evidence and open questions**: The radius-2 prediction (4.2 in one model) is within 0.1 of the cost threshold, and both models are two-point fits.
* **How to use it**: Before proposing a thinned row family with wider rows, count the expected rows changed per hop from the receptive-field radius; if it matches the all-rows family, the only saving is the matrix dimension, and the cost case must be checked against the all-rows engine, not against the dense foil.
* **Sources**: P2.1 R15.2, R15.6 (Round 15), R11.1, R13.1; Round 12c measurements.

### L30. Before speeding up or transferring a size-independent family, measure its capacity plateau and effective tangent rank at the target; if the rank does not grow with width, the family cannot reach the target accuracy.
* **Status**: PROVISIONAL
* **Applies to**: size-transferable NQS families (size-independent kernels or weight-shared generators), warm-start and pretraining schemes.
* **The lesson**: A size-independent family can only be as good as its own best state at the target, and transfer can at best reach that plateau faster. In the families built here, the plateau is a stationary point (one linear-method step improves it by almost nothing), and widening the network only re-parameterises a few dozen lookup tables of local hole counts: the effective tangent rank barely grows. Enlargement is then futile, and the transfer question is moot.
* **Evidence**: P4.2 R5.1 and R5.3 (jobs 452196, 604157, 659969; $4\times4$ open $t$–$t'$–$J$, $6+6$, 600 projected-SR steps): plateau relative energy error 5.97% at 426 parameters and 5.71% at 818 (apparent exponent $\alpha\approx0.07$ in $\epsilon\propto P^{-\alpha}$), effective tangent rank 34 of 426 and 48 of 818; the site-indexed projected NNBF reaches 0.56% with 1734 parameters on the same instance. At the plateau the best state in the span of the wave function and its derivatives improves the energy by at most 0.17% of the remaining error. P4.2 R9.4 and P4.1 R7 inherit this verdict.
* **Scope and limits**: One $4\times4$ open target; on the $4\times4$ torus, job 451914 trained the smaller 122-parameter MFNG family (not MFNG-O) from scratch to 1.96–2.13% relative error in 50 SR steps (upper bounds; 2 of 3 seeds still falling), so the torus plateau of that family is at most 1.96%; the transfer test there (P4.2 R9.5) was GATE-REFUSED, and the optimiser falsifier 704844 was INCONCLUSIVE.
* **Counter-evidence and open questions**: A family whose tangent rank grows with width would escape it.
* **How to use it**: Run a one-rung capacity pilot with a tangent-rank count before investing in transfer or speed-ups; stop if the rank does not grow.
* **Sources**: P4.2 R5.1, R5.3, R9.4; P4.1 R7; jobs 452196, 604157, 659969, 704844.

### L52. A sampled optimisation step whose line search is scored on the same samples that built the step overfits their noise, and can raise the true energy while the in-sample estimate reports a drop.
* **Status**: PROVISIONAL
* **Applies to**: sampled linear-method, natural-gradient (SR) and Newton-type steps for VMC, especially at few samples per parameter; any step-size selection by correlated reweighting of the samples that produced the step.
* **The lesson**: A sampled step is fitted to one draw: its direction partly follows that draw's noise in $S$ and the gradient. Scoring step lengths by reweighting the same draw evaluates the energy along a direction chosen to look good on exactly those samples, so the estimate is biased downward, more so at fewer samples per parameter and in small-eigenvalue directions of $S$. The line search then accepts a step the true energy rejects, and the in-sample estimate cannot see it.
* **Evidence**: P4.1 rung-1 smoke test (`tests/P4.1_cheap_su2_r19/logs/probe_sampled_che_1step_1thread.txt`): open $4\times3$ Hubbard, $5+5$, $U=8$, $t'=-0.25$, `che` (2637 parameters), 8192 exact i.i.d. samples (about 3 per parameter), truncated-metric step (cutoff $10^{-5}$, $\lvert z\rvert\le0.05$). The sampled energy was valid ($-7.79947\pm0.0047$ against exact $-7.805526$). The in-sample line search accepted $s=\tfrac12$, reporting $-7.79947\to-7.93034$; the exact energy rose to $-7.69576$, $R=-4.906$ (the step lost 4.9 times the state's gap to the ground energy). The same step with exact metric and line search gave $R=+0.269$. Rung 1 (job 731462, 4 steps, symmetrised Hamiltonian estimator) repeated it on every step (exact rises 4.9, 14.1, 24.0, 42.4 gaps while in-sample estimates dropped; SAMPLED-LOSES, $f=-78.6$).
* **Scope and limits**: One seed, one 12-site state; fresh-sample and non-symmetric follow-ups in L55. "Polished to stationarity" must also be checked across metric cutoffs (L29).
* **Counter-evidence and open questions**: Correlated-sampling line searches work in quantum-chemistry VMC with many more samples per parameter; the NQS crossover is open.
* **How to use it**: Score a sampled step's length on fresh samples (or a held-out half), report samples per parameter, and check one step against an exact energy on a small instance before trusting a sampled optimiser at scale.
* **Sources**: P4.1 rung-1 smoke test and job 731462; R18″; L29, L55, L62.

### L59. In one sampled SR step at about 6 samples per parameter (one start point, 16,384 samples), force noise dominates: the exact force recovers 60% of the exact step, the exact metric none.
* **Status**: PROVISIONAL
* **Applies to**: sampled SR or natural-gradient steps for NQS at a few samples per parameter; proposals that improve only the metric estimate (blocking, shrinkage, running averages).
* **The lesson**: The SR step solves $S\,\delta\theta=f$, with $S$ the covariance of the log-derivatives $O$ and $f=\mathrm{cov}(O,E_{\mathrm{loc}})$ the force. Swapping each for its exact value splits the noise: the exact metric with a sampled force did worse than fully sampled, the exact force with a sampled metric recovered 60% of the exact step. Near the nodes $O$ diverges, so the force has heavy tails; and $S$ and $f$ from the same samples have partly cancelling errors (the step is a ridge regression of $E_{\mathrm{loc}}$ on $O$), so improving one alone can make the step worse. So the exact-metric arm does not bound metric estimators; those routes were killed on their own values.
* **Evidence**: P4.1 round 22 noise split (SR-trained `che`, open $4\times3$ Hubbard, $5+5$, 2637 parameters, 16,384 samples, 3 seeds, shift $10^{-3}$; $\bar R$ = exact energy gain in units of the gap): fully sampled $0.016\pm0.022$; exact $S$, sampled $f$ $-0.024\pm0.011$; sampled $S$, exact $f$ $0.171\pm0.015$ of an exact 0.288; $S$ from 4N, $f$ from N $0.003\pm0.011$; plain 4N $0.095\pm0.012$. Killed on this split: blocked SR (R32, $-0.007$), running RLS metric (R35, $\le0.003$), Ledoit–Wolf, NERCOME and factor shrinkage (R36: 0.016, 0.021, $-0.011$). A force control variate (R37) cut force error 3.9–6.7-fold at 32.6 times the cost and still gave $-0.005$, $-0.008$.
* **Scope and limits**: One start point, one 12-site size, one-step probes, 3 seeds. Untested at polished endpoints or at 24 sites, where $P\gg N$ may make metric noise matter.
* **Counter-evidence and open questions**: Guided sampling (L61), which changes the draws for $S$ and $f$ together, helped. Mode-wise and grouped James–Stein shrinkage of the force (R39, killed at T1, per-leaf critic owed) also lowered the gain (0.005, −0.008; guided draws 0.062, 0.056 against 0.086), because most force modes have SNR below one; with R36 the shrinkage analogy fails for both metric and force. Sample reuse (R34) was killed (G4).
* **How to use it**: Before building a better metric estimator, run the two-swap noise split on a small exact instance; spend effort on the force, or on $S$ and $f$ together.
* **Sources**: P4.1 R32, R35, R36, R37, R39 (KILLED), R34; `tests/P4.1_cheap_su2_r25/noise_split.py`, `RULE_B.md`, `RULE_E.md`; log `leaves/P4.1/log/round-22.md`.

### L60. At linear-method-polished 12-site endpoints, exact-gradient L-BFGS, truncated Newton and Anderson schemes (on the ladder iterates or the raw direction) were not faster per CPU-minute than the cutoff-ladder linear method; only exact-metric whitening reached its rate.
* **Status**: PROVISIONAL
* **Applies to**: exact-sum or low-noise polishing of NQS with thousands of parameters; choosing quasi-Newton, Newton-type or multisecant optimisers over the linear method.
* **The lesson**: After ladder polish (L29) the gains decay linearly (ratio 0.76–0.98 per step), and exact gradients are cheap (0.12 CPU-min against 2.9 per ladder build for `che`), suggesting many gradient steps per build. For L-BFGS (R27) and truncated Newton (R29) the stated mechanism is ill-conditioning: learning curvature from gradients spends the iterations in near-flat Hessian directions. Anderson extrapolation failed both on the ladder iterates, whose map is not smooth (cutoff and step factor jump, R30), and on the raw fixed-cutoff direction, whose map was smooth (successive cosines 0.95–0.97, R41): parallel, shrinking residuals make the secant model lengthen a step the line search had already cut back. Only exact-metric whitening brought a gradient method up to the ladder's rate, not past it.
* **Evidence**: P4.1, open $4\times3$ Hubbard, `che` (2637 parameters) and `pcg`, job 742206 endpoints, one thread, exact sums; rate per CPU-minute over the ladder's last-5-step rate ($7.27\times10^{-6}$ `che`, $5.51\times10^{-6}$ `pcg`): L-BFGS (R27) 0.17 (`che`), 0.13 (`pcg`); trust-region Newton-CG (R29) 0.05; Anderson on ladder iterates (R30) 0.80, never beating the plain step; Anderson on the raw direction (R41) 0.83, 5 of 6 candidates lost to the plain step; metric-whitened L-BFGS from one exact $S$ build (R28) 1.12 (second half 0.99), short of the pre-registered 3. R28's refreshed-metric extension was KILLED at T0: the best credited cycle reaches 1.69–1.79×, and 3× needs a build 6 times cheaper than exact.

* **Counter-evidence and open questions**: Untested: L-BFGS from unpolished starts; Anderson with depth $m\ge4$, on `pcg`, or with a line search on the extrapolated direction. R28's T0 kill has no critic review yet.
* **How to use it**: Before swapping the optimiser at a polished endpoint, measure its rate per CPU-minute against the ladder over a few CPU-minutes; expect a large gain only from changing the conditioning (a metric), not the update rule.
* **Sources**: P4.1 R27, R29, R30, R41 (KILLED, T1), R28 (KILLED, T0); `RULE` files in `tests/P4.1_cheap_su2_r25/`, `_r27/`, `_r41/`; logs `round-22.md`, `round-23-R30.md`, `round-24-R28`, `round-26-R41`; L29.

### L69. Subsampling the rows of a sampled metric pays only where the rows are computed for the metric alone; in sampled VMC every drawn row also feeds the force, so the saving is bounded by the Gram product's share of a step.
* **Status**: PROVISIONAL (2026-11-17; T0 operation count, kill upheld by the per-leaf critic)
* **Applies to**: leverage, sketch or other row-selection schemes for the SR or linear-method metric $S=Y^{\mathsf T}Y$ built from sampled log-derivative rows.
* **The lesson**: In exact-sum polishing the rows themselves are the expense, so building fewer of them saves most of the metric (L66). In sampled VMC the force $f=\langle O\,e\rangle$ needs the row of every drawn configuration, so choosing a subset of rows for $\hat S$ saves only the Gram product, and estimating each row's leverage costs about as much as that product. A metric built from fewer rows than the force also breaks the shared-sample error cancellation between $S$ and $f$.
* **Evidence**: P5.1 R51.12 (KILLED, T0): leverage of $N$ sampled rows costs $\mathcal O(NP^2)$, the Gram's own cost, and a $k$-column sketch $\mathcal O(NPk)$; at 24 sites the local energy is 85–90% of a step (P4.1 R34), so the Gram's share caps any saving at about 10–15%; S–f cancellation from P4.1 R35, R37; the exact metric recovers none of the sampled step's loss (L59). Contrast P5.1 R51.3 at exact sums: rows 1.14 of 1.9 CPU-min per build.
* **Scope and limits**: Argument and operation counts, no run; at very large $P$ and small $N$ the Gram could dominate, but MinSR's sample-space solve already covers that regime.
* **Counter-evidence and open questions**: Leverage as a sampling distribution for the force is a different question (P5.1 R51.11, pending).
* **How to use it**: Before subsampling a metric, check which other estimator consumes the same rows; if one does, the saving is only the Gram share.
* **Sources**: P5.1 R51.12, R51.3; log `round-05.md`; L59, L66.
### L70. SGD variance-reduction devices did not transfer to sampled SR in the forms tried: STORM recursion on the step or on the metric and force lost to fresh draws, and reshuffling only matches them, because sampled SR has no finite sum whose error can cancel.

* **Applies to**: SVRG/SARAH/STORM recursions, anchor control variates and reshuffling in sampled SR.
* **The lesson**: SGD variance reduction works on a finite sum: per-sample terms are recomputed on the same data, and reshuffled mini-batch errors sum to zero per epoch. ## About testing and measurement

### L31. Swapping exact and approximate parts of jointly optimised factors is not an error budget, because each part is co-adapted to the other's errors.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic)
* **Applies to**: error attribution between factors of any jointly trained model (sign and amplitude of a wave function, orbitals and Jastrow, encoder and decoder), including Shapley-type splits.
* **The lesson**: Replacing one trained part by its exact counterpart, keeping the other trained part, does not remove "that part's error": the kept part was trained to compensate the replaced part's errors and is wrong for the exact partner. The resulting shares can be negative or exceed the total error, so they measure incompatibility between the trained halves, not error content. A budget must instead fix one part (for example the signs) and re-optimise the other to its best.
* **Evidence**: P1.1 R2 (job 329057, seed 1234; three $4\times3$ Hubbard tori, NNBF widths 8–128): on all 15 states both hybrids lie above the trained energy. On $5+5$, $U=8t$, width 128: total error $\Delta E_{\mathrm{tot}}=0.166t$, exact-sign hybrid error $0.352t$, exact-amplitude hybrid error $1.324t$, so the Shapley shares are sign $+0.569t$ and amplitude $-0.403t$; the amplitude share is negative for all 12 foil and NNBF states ($-0.075t$ to $-0.977t$).
* **Scope and limits**: One budget question on three small tori; the co-adaptation argument is general.
* **Counter-evidence and open questions**: For independently obtained parts (not jointly trained) swaps can be meaningful; only the 3 UHF states gave two positive shares.
* **How to use it**: Attribute error by constrained re-optimisation (fix one part, optimise the other), as P1.1's fixed-sign budget $E_{\mathrm{sign}}$ does.
* **Sources**: P1.1 R1, R2; job 329057; Westerhout et al., Nat. Commun. 11, 1593 (2020).

### L32. Only the best energy at fixed signs is a sign-only error measure; configuration-weighted sign accuracy and lattice fixed-node energies mix in amplitude effects.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic)
* **Applies to**: measuring how much of a fermionic variational state's error is due to its sign structure, on lattices.
* **The lesson**: The sign-mismatch weight $w_{\mathrm{sign}}$ (probability weight of configurations with the wrong sign) is not an energy: a sign error between configurations joined by small matrix elements costs almost nothing, and for any fixed per-region accuracy the chance of a fully right sign pattern decays as $e^{-cV}$, so $w_{\mathrm{sign}}$ saturates with size. The lattice fixed-node energy $E_{\mathrm{FN}}$ is not sign-only either: its sign-flip term $\sum_{\mathbf n'}H_{\mathbf n\mathbf n'}\psi(\mathbf n')/\psi(\mathbf n)$ over sign-violating pairs depends on the guide's amplitudes, so $E_{\mathrm{FN}}$ is only an upper bound on $E_{\mathrm{sign}}$, the lowest energy of any state with the given signs. The stoquastic lower bound on $E_{\mathrm{sign}}$ is too loose to certify a large sign fraction.
* **Evidence**: P1.1 R3 (job 329057, width 128): $w_{\mathrm{sign}}=0.197$, 0.029, 0.0063 on the three tori (31-fold range) while the sign fraction $f_E^{\mathrm{up}}$ is 0.77, 0.61, 0.65; widening from 8 to 128 cut $w_{\mathrm{sign}}$ 3.3 times but $\Delta E_{\mathrm{sign}}$ only 1.6 times. P1.1 R4: fixed-node sign fractions 0.665, 0.827, 0.756 against $f_E^{\mathrm{up}}$ 0.607, 0.772, 0.652, and 0.845 against 0.141 on a 6-site smoke. P1.1 R1: the stoquastic lower bound on $E_{\mathrm{sign}}$ lay $2.7$–$4.1t$ below $E_0$ on every instance.
* **Scope and limits**: Three $4\times3$ tori, unprojected networks.
* **Counter-evidence and open questions**: A non-vacuous lower bound on $E_{\mathrm{sign}}$ is an open row of P1.1's reopening ledger.
* **How to use it**: Report sign errors as $\Delta E_{\mathrm{sign}}$ (fixed-sign optimum) with its upper and lower brackets; never compare $w_{\mathrm{sign}}$ or $E_{\mathrm{FN}}$ across leaves as a sign fraction.
* **Sources**: P1.1 R1, R3, R4; job 329057; ten Haaf et al., PRB 51, 13039 (1995); Loehr and Clark, arXiv:2510.26906.

### L33. Every comparison between separately trained ansätze is also a comparison of how far each optimiser got, so rankings need polished arms or a check of the remaining optimisation gap.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic); restored after compaction per cross-node critic 2026-11-17

### L36. When the parameter count reaches about half the projected sector dimension, width comparisons measure sector fitting and carry no capacity or decision-rule information beyond exact-diagonalization size.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic)
* **Applies to**: width and capacity comparisons of NQS on exact-diagonalization clusters, especially with symmetry projection.
* **The lesson**: A symmetry-projected network on a small cluster only needs to represent a vector in the projected sector, of dimension $d_{S\chi}$. ### L37. An exact-inverse or exact-matrix reference certifies the machinery, not the information source; a premise run needs a matched Hamiltonian-only foil before its information source is credited.

### L39. Exact-sum clusters cannot test claims whose value appears only at large size, such as a cheaper projection or a local-versus-global split, because there projection is free and every patch covers most of the lattice.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic)
* **Applies to**: T1 tests on clusters small enough for exact sums (up to about 16 sites) of routes whose claim is a cost advantage or a locality structure.
* **The lesson**: In exact-sum tests every amplitude of the sector is computed anyway, so symmetry projection costs nothing extra, and a route whose only advantage is cheaper or partial projection cannot win or lose on the measurable metric. On a $4\times4$ cluster a range-1 patch with diagonal bonds, or two stacked plus-shaped layers, already sees nearly every site, so "local" and "global" features coincide and a split between them cannot be measured.

* **Counter-evidence and open questions**: Sampled tests at 30 to 100 sites could test them, at a cost the gate did not fund.
* **How to use it**: Before a T1, ask whether the route's advantage exists at the T1 size; if not, the route needs a sampled test at a size where it does, or it waits.
* **Sources**: P1.3 R3.4, R7.4; P2.1 R2.6, R3.4, R6.4, R7.2; P4.1 R42, log `round-28.md`.

### L40. A toy instance may decide a rule only if it is representative: it has a spectral gap, its sector is not nearly spanned by the method's subspace, and its noise and infidelity match the real states.

* **Counter-evidence and open questions**: None.

### L41. Ensembles of seeds or widths of one architecture share their bias, so their disagreement, or an extrapolation through them, under-states the error.
* **Status**: PROVISIONAL
* **Applies to**: error bars from seed spread, architecture consensus, capacity ladders, multi-seed Ritz and averaging of independently trained corrections.
* **The lesson**: Independently trained copies of one architecture make similar errors, because the error comes from what the family cannot represent, not from random optimisation noise. Their spread measures the noise part only, and an extrapolation along width keeps the shared part: widening removes amplitude error while the sign-borne observable error barely moves.
* **Evidence**: P3.1 R6.4, R7.7, R9.4 (job 698163): the real $4\times4$ seeds 11, 22, 33 have the same sign of the observable error in all three channels. P3.1 R2.3 (job 329057): width lowered the energy variance two- to threefold while the sign-borne largest bond-pair error moved only from 0.0273 (width 8) to 0.0255 (width 128); a cross-width extrapolation under-stated the error on 3 of 3 widest states. P3.1 R7.6: a Ritz-trained auxiliary is a two-member capacity ladder.
* **Scope and limits**: One $4\times4$ instance (3 seeds) and the $4\times3$ $4+4$ torus. No ensemble over fields was tested.
* **Counter-evidence and open questions**: Ensembles of different architectures with independent biases could do better; not tested.
* **How to use it**: Never report seed spread as an error bar for a systematic error; check whether ensemble members share the sign of their errors.
* **Sources**: P3.1 R2.3, R6.4, R7.6, R7.7, R9.4; jobs 329057, 698163; Viteritti et al., arXiv:2604.21978.

### L42. An extrapolation through separately sampled states fails when the signal it extrapolates is smaller than each state's statistical error.
* **Status**: PROVISIONAL
* **Applies to**: capacity-ladder, hybrid and zero-variance extrapolations of observables through several sampled variational states.
* **The lesson**: Each state on the ladder carries its own Monte Carlo error. If the differences between them (the signal the fit uses) are below those errors, the fit's slope and endpoint are noise, and a fit through one ensemble anchors neither.
* **Evidence**: P3.1 R5.2 ($4\times4$ open instance, $10^5$ draws): 0 of 7 injected items tracked; spin over-shot 2.6–2.8 times. P3.1 R6.1 (job 452272): 0 of 4 tracked; the jackknife standard error was about the size of the error itself, so the method abstained almost everywhere. P3.2 R6.5: a sampled single Lanczos step per branch at $2\times10^4$ draws, whose gain is below each branch's sampling error, decided almost nothing (right 1.3%, wrong 0.6%).
* **Scope and limits**: One instance, injected checks.
* **Counter-evidence and open questions**: None.
* **How to use it**: Compare the ladder's signal with each state's standard error before fitting; if it is smaller, sample more or drop the extrapolation.
* **Sources**: P3.1 R5.2, R6.1; P3.2 R6.5; jobs 452146, 452272.

### L43. A warm-started or transferred arm must be scored against its own starting state and against training from scratch, not only against the foil.
* **Status**: PROVISIONAL
* **Applies to**: warm-start, oracle-start and transfer tests of NQS (across sizes, Hamiltonians or architectures).
* **The lesson**: A warm-start arm tests a basin only if its start is measurably better than the cold runs; a transferred state can start worse than doing nothing, because an exactly fitted but under-identified source network carries arbitrary content in its null directions; and a head start that training uses up in a few dozen steps is worth a speed-up of about 1 on an offset-free clock. * **Scope and limits**: Exact-diagonalization sizes; one transfer family.
* **Counter-evidence and open questions**: None.
* **How to use it**: Score every warm or transferred start at step 0 against the untrained prior and the cold start, and report the offset-free speed-up.

### L44. A test bed for competing orders must put both competitors in the same symmetry sector, which needs a two-parameter scan because same-sector degeneracies have codimension 2.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic)
* **Applies to**: designing small-cluster tests of methods that decide between competing orders.
* **The lesson**: Competitors in different symmetry sectors can be separated by projection or level spectroscopy, which makes the decision trivial and the test uninformative. The physically relevant competitors (stripes against $d$-wave) share a sector on clusters commensurate with both. By the von Neumann–Wigner rule, two same-sector levels generically meet only on a codimension-2 set, so a one-parameter sweep finds avoided crossings, and an exact conical intersection needs a second parameter (here hopping anisotropy $t_y$ added to $t'$).
* **Evidence**: P3.2 R1.2: on the $4\times3$ cluster the earlier "same-sector" competitor was a spin triplet at momentum $(\pi,\pm2\pi/3)$, $0.086t$ above $E_0$, while the in-sector gap was $0.515t$. P3.2 R1.4: its test's competitors were mirror-even and mirror-odd. P3.2 R2.5: no twist separates same-sector orders. P1.3 R2.3: an irrep scan meets same-sector competitors. P3.2 then built its test bed as a same-irrep crossing in $(t',t_y)$.
* **Scope and limits**: Small Hubbard clusters.
* **Counter-evidence and open questions**: None.
* **How to use it**: Run an exact sector analysis of every proposed test instance and place targets on a two-parameter crossing.
* **Sources**: P3.2 R1.2, R1.4, R2.5; P1.3 R2.3; master Revision Log item 23 (round-1 critic).

### L47. Cost gates must be predicted from per-sample operation counts of the real algorithm and from measured speeds of compiled kernels, not from multiply-add totals, stored full-basis vectors or interpreter timings.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic)

### L54. A curvature screen normalised by the $\psi^2$-weighted variance of the direction rewards spikes on near-node configurations, so it can open a phase family whose trained carrier then loses to width; normalise by $\max\lvert g\rvert^2$ or score the projection onto the free direction.
* **Status**: PROVISIONAL
* **Applies to**: second-order (curvature) screens of a candidate parameter or feature span at a trained real state, before training a phase or sign carrier on it; any screen dividing an energy change by a $\psi^2$-weighted norm of the direction.
* **The lesson**: At a real trained state the energy change along a phase direction $g$ is second order, $q(g)$, and the screen $\lambda(S)=\min_{g\in S}q(g)/\mathrm{var}_{\psi^2}(g)$ asks whether the span $S$ has a descending direction. The $\psi^2$ weight gives a direction concentrated on a few near-node configurations (huge determinant ratios) a tiny norm and a large ratio, so the screen finds strongly negative $\lambda$ that a bounded phase cannot realise. Normalising by $\max\lvert g\rvert^2$, or scoring the part of the free-phase descent direction that $S$ captures, measures the reachable gain.
* **Evidence**: P1.2 reopening-ledger row 4 (`tests/P1.2_unanchored_antisymmetry_r10/`, 3.3 CPU-min; unprojected $6\times2$ and $4\times3$ $t$–$t'$–$J$ toys, frozen width-6 foils, 2 seeds): the ratio-product span scored $\lambda(S)=-9.73$, $-10.22$ ($6\times2$) and $-4.48$, $-4.43$ ($4\times3$) against $+1.01$ to $+1.40$ for equal-rank random spans: FAMILY-OPEN. Read afterwards: the unrestricted minimum sat on one configuration ($-2.5\times10^4$ to $-6.5\times10^5$); the eigenvector lived on 12–86 configurations against 170–636 for the free phase; its gain $q/\max\lvert g\rvert^2$ was 30–300 times below the free phase's; the captured free direction ascends at $4\times3$. The trained carrier (P1.2 R10.1) then lost to width ($r=1.08$, 1.01) with 10–12 times width's added parameters and 75–90% of its flipped weight on near-node configurations; reverting those flips returned the sign error to within 3.3% and 2.8% of the foil.
* **Scope and limits**: One span family, two 12-site toys, two seeds, unprojected frozen foils.
* **Counter-evidence and open questions**: The amended screen was not validated on a span that then trained into a gain.
* **How to use it**: Normalise curvature screens by $\max\lvert g\rvert^2$ or score the projection onto the free direction, and report the screening direction's participation before a negative screen licenses training.
* **Sources**: P1.2 R10.1, reopening-ledger row 4; `tests/P1.2_unanchored_antisymmetry_r10/`, `tests/P1.2_unanchored_antisymmetry_r11/`; L23, L38.

### L67. One-step quantities missed multi-step behaviour by 2–4× in both directions on one 12-site state (rate overstated 3–4×, sample need overstated more than 2×), so they cannot stand in for multi-step needs without calibration.
* **Status**: PROVISIONAL (one state, one size)
* **Applies to**: one-step screens (direction fidelity, counterfactual gain per step, one-step noise splits) used to predict the rate, step count or samples per step of a multi-step sampled optimiser, or their growth with size.
* **The lesson**: A one-step quantity is measured at one state and does not see the noise that accumulates along the path, nor how the optimiser's own states differ from the reference states. It can err either way: a one-step gain at good states overstates the rate the optimiser sustains, while a one-step fidelity at the start can demand more samples than the multi-step run actually needs. Neither error has a known sign in advance, so a one-step screen ranks or kills only after calibration against multi-step data.
* **Evidence**: P5.1 R51.9 (12-site `che`, guided SR, step 0.005): the one-step counterfactual rate at R38's states was $0.0078\pm0.0006$ of the gap per step, against 0.0020–0.0025 sustained by the fixed-length optimiser at states of similar $R$ (R51.1, arm A): 3–4× high. From R51.1's start, step 1 kept $\phi$ = 0.45, 0.57, 0.82 of the exact step's gain at 16k, 66k and 262k samples, so $\phi\ge0.9$ needs more than 262k, while the multi-step run reached 98% of the polished value at 262k and 95% at about 115k: more than 2× in the opposite direction. A stationary noise-ball model was off by 2.7× at 262k (L65).
* **Scope and limits**: One 12-site state, one optimiser and step length; the cross-size ratio of a one-step quantity is untested.
* **Counter-evidence and open questions**: A ratio across sizes might be right even if each value is off; R51.10's calibrated one-state predictor failed that test (killed; start and end $\kappa$ ratios in L78).
* **How to use it**: Do not replace a multi-step measurement with a one-step proxy; if a proxy is needed, calibrate it against multi-step data at two sizes first.
* **Sources**: P5.1 R51.9 (KILLED, T0), R51.1 (T1a, T2); jobs 752885, 759974, 761860; `logs/preflight_S4x3_exact.txt`; L59, L65.

### L68. A two-sided expressivity comparison against an exactly projected spin-reading network costs $\binom{N_s}{N_s/2}$ network evaluations per amplitude, so on a CPU budget of hundreds of hours it is limited to about 16 sites near the fillings tried; beyond that only one-sided tests, which can show a loss but not its absence, are possible.
* **Status**: PROVISIONAL (2026-11-17; operation counts, rescoped by the per-leaf critic)
* **Applies to**: comparisons of a symmetry-restricted (for example charge-only, exactly $S=0$) ansatz with a richer spin-reading network projected onto the same sector, used to ask whether the restriction costs expressivity.
* **The lesson**: Exact SU(2) projection of a network that reads spins sums the spin orbit of each configuration: $\binom{N_s}{N_s/2}$ network amplitudes per amplitude, with $N_s$ the number of singly occupied sites (L11). A two-sided verdict (loss or no loss) needs this arm converged. Beyond its budget only one-sided tests remain: an unprojected, spin-flip-symmetrised or $\hat S^2$-penalised comparator, or fidelity to an $S=0$ teacher whose $\langle\hat S^2\rangle$ is checked. Each bounds the projected family from one side, so a clear win shows a loss, but a non-win says nothing. This is a budget statement, not a structural one: the cost depends on $N_s$, not on the number of sites.
* **Evidence**: P4.1 R44 (T0): $4\times4$ Hubbard, $N_e=12$–14, typical $N_s=10$–12, 252–924 amplitudes per amplitude; a 262,144-sample step about 500 times R51.1's 2.2 CPU-min `che` step, about 18 CPU-h per step; exact sums at $4\times4$ $6+6$ about 430 CPU-h per 4000-iteration arm. At open $8\times3$, $N_e=20$ ($N_s\approx16$–18): $1.3$–$4.9\times10^4$ evaluations per amplitude. At strong doping ($N_e=8$) $\binom{N_s}{N_s/2}\le70$, so exact projection stays cheap far beyond exact-diagonalisation sizes. One-sided forms: P4.1 R46 (penalised comparator, KILLED at G2, informative side predicted at p about 0.1) and R47 (teacher fidelity, LIVE; the bound needs the teacher's $S\ne0$ weight and a plateaued restricted arm).
* **Scope and limits**: CPU counts at the fillings tried; a GPU batches the orbit sum well, shifting constants but not the growth in $N_s$. No one-sided test has run yet.
* **Counter-evidence and open questions**: Whether a one-sided test's informative side is likely enough to be worth running (R46: not at R42's budget; R47: no, contamination swamps it).
* **How to use it**: Count $\binom{N_s}{N_s/2}$ at the target filling before planning a projected spin-reading arm; at small $N_s$ use it, otherwise pre-register a one-sided test and state that no detection settles nothing.
* **Sources**: P4.1 R44 (KILLED, G4), R46 (KILLED, G2), R47 (SHELVED, G2); `round-30-critic.md`, `round-34-R47.md`; L11, L33, L39.

### L72. A count threshold within about 1 sd of its predicted count needs a stage-2 seed clause (as R43's rule had); otherwise the verdict can turn on a coin flip.
* **Status**: PROVISIONAL (one instance, P5.1 R51.5; 2026-11-18)
* **Applies to**: pre-registered kill or pass rules that compare a count (steps that rose, seeds that pass, items over a line) with a fixed threshold.
* **The lesson**: When the expected count sits within about one binomial sd of the threshold, a single run decides the verdict by sampling noise rather than by the effect. The rule should say in advance what happens near the line: a second seed or a longer run, triggered when the count lands within about one sd, and final otherwise.
* **Evidence**: P5.1 R51.5 premise arm (job 769669): energy rose on 83 of 240 steps against a line of 80 (more than a third), binomial sd at $p=1/3$ about 7.3, so the margin was about 0.4 sd and the rule had no near-line clause; the kill stood under the rule and was later supported by matched-progress rise rates (0.35 against 0.03). P4.1 R43's rule (`tests/P4.1_cheap_su2_r43/RULE.md`) instead requested a seed 2 if any $\rho'_s$ fell within 0.05 of a line; its margin was 0.25 and the clause was not triggered.
* **Scope and limits**: One near-line case; the 1 sd trigger is a judgement, not calibrated.
* **Counter-evidence and open questions**: None yet; L45 (abstaining rules) is the related decision-rate lesson.
* **How to use it**: Before registering a count threshold, predict the count and its sd; if the line is within about 1 sd, add a stage-2 seed clause with its capped cost.
* **Sources**: P5.1 R51.5 card, logs `leaves/P5.1/log/round-08-R51.5.md`, `round-09-critic.md`; P4.1 R43; L45, L50.

### L74. A gain read from an oracle envelope over runs stopped at one step count can be a censoring artefact, so continue the smallest-batch arm to the target before crediting a schedule or a larger batch.
* **Status**: PROVISIONAL (one case, 2026-11-18)
* **Applies to**: schedules (samples per step, step length) or batch-size comparisons built from stored fixed-length runs; any time-to-target statistic with arms stopped before the target.
* **The lesson**: Stopping arms at the same step count stops the cheap-per-step arms at the smallest draw budget, so they are censored before high targets. An envelope that switches to larger arms then appears to beat every fixed arm while only exploiting the censoring, and "not reached in 120 steps" gets misread as "needs a bigger batch".
* **Evidence**: P5.1 R51.15 T1 on R51.1's $4\times3$ guided arms (120 steps each, $N$ 16k, 66k, 262k): the oracle envelope reached $0.90R_{\rm pol}$ at 4.8M draws against 6.75M for the best fixed arm (1.41×) and 0.95 at 12.1M against 22.0M (1.83×) → PASS. Continuing the 16k arm 332 steps (R51.16 task 0, job 769213) first reached 0.90 at 4.26M and 0.95 at 6.67M, below the envelope at both. The same censoring had shaped L65's earlier reading.
* **Scope and limits**: One state, one seed; one envelope.
* **Counter-evidence and open questions**: A schedule may still help at targets above 0.95, untested.
* **How to use it**: Run the smallest-$N$ arm to the target or to the largest arm's draw budget before crediting an envelope; mark censored arms, and count them only in the direction that works against the claim.
* **Sources**: P5.1 R51.15, R51.16, R51.1; jobs 759974, 761860, 769213; `tests/P5.1_r05_gen/RULE_adaptN.md`, `envelope.json`; log `round-09-scoring.md` §4; L33, L65.

### L75. A pre-registered rule must state its reference energy $E_0$, or the gap, as a number, not only thresholds derived from it, because scorers otherwise normalise to different references under one threshold.
* **Status**: PROVISIONAL (one case, verdicts unchanged; 2026-11-18)
* **Applies to**: rules scored on a normalised progress measure (fraction of a gap, relative error) when more than one valid reference exists (levels of different sectors, a polished energy).
* **The lesson**: $R=(E_{\rm start}-E)/(E_{\rm start}-E_0)$ is defined only with $E_0$. If the rule fixes numeric thresholds computed on one gap but names $E_0$ only in words, a scorer that takes another valid $E_0$ rescales $R$ under a fixed threshold, making it stricter or laxer, and code that joins stored $R$ on one scale with recomputed $R$ on another mixes both.
* **Evidence**: P5.1 round 9, $4\times3$ `che`, $E_{\rm start}=-7.805526$: gap 0.022373 ($E_0=-7.827899$, the exact level used by P4.1's polish and R51.1's stored $R$) against 0.023111 ($E_0=-7.828637$, lowest (+,+) level) used by the new scoring script. The rules fixed $R_{\rm pol}$ 0.7475, threshold 0.6728 and 7.41M on the first gap; the code joined arm A's stored $R$ (step 60: 0.494; 0.478 on the second gap) to a continuation on the second, giving 5.85M where the registered scale gives 4.51M. R51.16 (3.26 against 2.53) and R51.11 (0.43 against 0.41) kept their verdicts on both scales.
* **Scope and limits**: One case; neither verdict changed.
* **Counter-evidence and open questions**: None.
* **How to use it**: Write $E_{\rm start}$, $E_0$ and the gap as numbers with their source file in the rule; compute $R$ from absolute energies on that gap only; re-score one stored arm as a check.
* **Sources**: P5.1 R51.16, R51.11; log `round-09-scoring.md` §1; `tests/P5.1_r05_gen/score_scales.py`, `score_common.py`; L62, L72.

### L78. Neither the start nor the end one-state $\kappa$ tracked the growth of the multi-step sample need from 10 to 12 sites, and the two sizes' needs were measured at different optimisation stages, so a size ratio of sample needs must compare like stages.
* **Status**: PROVISIONAL (one size step, one seed; T0 from stored data, 2026-11-18)
* **Applies to**: size-scaling tests of the samples per step a sampled optimiser needs (against each size's noise-free run), and one-state predictors of that need; extends L67.
* **The lesson**: The ridge noise-to-signal ratio $\kappa$ (effective dimension × residual variance / signal) taken at one state does not predict the need's growth, whether taken at the start or at the end of the run, and the two disagree with each other by orders of magnitude. Separately, a fixed step count can leave one size on a plateau and another still descending; needs measured there differ for reasons unrelated to size, so the ratio confounds stage with size.
* **Evidence**: P5.1 R51.28, R51.29 on R51.8 (open $5\times2$ and $6\times2$, guided, $\tau$ 0.005, steps 61–120): need 31,280 → 118,600, ×3.79; $\kappa$ at the starts ×0.70 (R51.10), $\kappa_{\rm guided}$ at the exact arms' ends 10.5k → 1.89M, ×180 (`tests/P5.1_vr_r12/results/vr_S*_end.json`). Stage: the $5\times2$ noise-free arm is a limit cycle (slope z −1.1) that removed 45% of the gap to $E_0$; the $6\times2$ one still descends (z −3.7), removing 81%; endpoint exact step $x^{\mathsf T}Sx$ 3.7e-3 against 2.4e-4.
* **Scope and limits**: One size step, one seed per arm; whether matched stages change the ratio is untested (R51.7's CONT continuation, job 773528, reports it).
* **Counter-evidence and open questions**: A ratio near the support growth (×3.52) at matched later stages would remove the confound.
* **How to use it**: Report each size's noise-free stage (slope, fraction of gap removed) beside a need ratio; continue or truncate arms so that both sizes are on a plateau, or both descending, before reading a scaling exponent.
* **Sources**: P5.1 R51.28 (KILLED, T0), R51.29 (MERGED), R51.10, R51.8; log `leaves/P5.1/log/round-16.md`; L67.

## About process and compute

### L48. Almost half of the compute spent before the compute gate in this run changed no decision, and most of it could have been predicted by a scaling argument that cost no compute.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic)
* **Applies to**: compute planning in research brainstorms and method studies on clusters.
* **The lesson**: Before the compute gate existed (2026-11-10 to 2026-11-16), jobs were submitted when a route reached a decisive-test design, without asking whether a cheaper argument could settle it. The largest no-change spends were decisive arrays on routes that a Gate 4 scaling argument later killed with no compute, size ladders whose outcome the same argument predicted, and pilots repeated until a tie-break rule fired.
* **Evidence**: Master compute ledger (`sacct`, 2026-11-16): 66 jobs, 28,162 CPU-h; 21 jobs worth 13,388 CPU-h (48%) changed no decision. P2.1's round-5 decisive array 526080 (85 tasks, 8,906 CPU-h, 32% of the total) ended AMBIGUOUS, and its routes were then killed at T0 by a Gate 4 argument (P2.1 R3.1, R3.2). P4.1's size ladder 686990 (about 13,000 CPU-h of work, cap 107,520) was cancelled before it started because the T0 argument already predicts its outcome (P4.1 R1-L); the generality job 637776 spent 1,424 CPU-h before cancellation (R1-G). P3.1's ESR0 extension 618646 spent 169 CPU-h before ESR0 failed Gate 4 (R7.1a). P1.3's ladder 451976, 507178, 507179 (1,527 CPU-h) returned UNCLEAR three times before the CAPACITY tie-break. In all, 13,388 of 28,162 CPU-h (47.5%) changed no decision, and 10,499 CPU-h of it (jobs 526080, 637776, 618646) went to routes later killed by a Gate 4 argument.
* **Scope and limits**: One brainstorm; the "changed a decision" column was read from the leaf texts.
* **Counter-evidence and open questions**: Some no-change jobs (wall-cap hits) were plain bad luck rather than predictable.
* **How to use it**: Run the T0 scaling and dominance arguments (Gate 4) before any job above about 10 CPU-h, and write the predicted verdict down; if the prediction is confident, record it instead of running the job.
* **Sources**: Master `## Compute Ledger` (historical ledger and observations); P2.1 R3.1, R3.2; P4.1 R1, R1-L, R1-G; P3.1 R7.1, R7.1a; P1.3 R3.1; jobs 526080, 686990, 637776, 618646, 451976, 507178, 507179.

### L49. Caps per array task do not bound what an array job spends; compute caps must be set on the total of a job.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic)
* **Applies to**: compute-budget rules for Slurm array jobs and any batch system with per-task limits.
* **The lesson**: A per-task cap (CPUs times wall limit per task) looks small, but an array multiplies it by the number of tasks, and resumes and extensions multiply it again. Without a cap on the job total, large spends pass every per-task check.
* **Evidence**: Master compute ledger: P2.1's 85-task array 526080 spent 8,906 CPU-h without breaking any per-task cap; eight jobs used more than 1,000 CPU-h each without the user's approval; the cancelled jobs' combined caps were about 285,700 CPU-h, almost all in four P4.1 size-ladder and generality jobs; the queued 24-site reference 687302 still held 3,840 CPU-h of wall limit at the pause.
* **Scope and limits**: One cluster and one brainstorm.
* **Counter-evidence and open questions**: None.
* **How to use it**: Gate every job on its total CPU-hours (tasks times CPUs times wall limit), including resumes, as `compute_gate.py` now does.
* **Sources**: Master `## Compute Ledger`; SKILL.md rule 6; job 526080.

### L50. Before planning on, resuming or extending a job, check from stored data whether its pre-registered rule can still change the verdict.
* **Status**: ESTABLISHED (2026-11-17, cross-node critic)
* **Applies to**: pending, running or resumed jobs whose verdict depends on a pre-registered rule over seeds or items.
* **The lesson**: Once enough seeds or items are stored, a pre-registered rule may already be decided whatever the remaining tasks return. Running them, or branching the plan on their outcome, spends compute and time on a known answer. The same holds for resumes and extensions: if no outcome of the resumed run changes the decision, it should not run.
* **Evidence**: P1.2 R5.1: with all ten control runs stored, the 5-seed sign-error ratio was at least $0.782>0.7$ whatever seeds 44 and 55 gave, yet job 553724 spent 1,090 CPU-h before 3 of its 8 tasks were cancelled. P3.1 R10.1d: the T3 705951 printed INCOMPLETE, but seed 11 could lift the best foil to 8 items at most against a PASS threshold of 6 and a KILL threshold of 9, so the verdict was already AMBIGUOUS.
* **Scope and limits**: Two cases in one brainstorm.
* **Counter-evidence and open questions**: None.
* **How to use it**: Before every resume, extension or plan branch, run the aggregate on stored data with the missing items set to their best and worst values; if both give the same verdict, stop.
* **Sources**: P1.2 R5.1; P3.1 R10.1d; jobs 553724, 705951.

### L51. Removing the reason a route was killed, or rescuing it after the result, is not a new mechanism; a revival needs its own pre-registered test with a cost model whose inputs all come from one instance and size.
* **Status**: PROVISIONAL
* **Applies to**: reopening killed routes, and post-hoc combinations proposed after a route fails.
* **The lesson**: A revived route whose only change is to argue away its kill reason tends to pass by mixing measurements from different settings, and a rescue chosen after a result (adding a known trick to a failed route) is a constant-factor combination of known pieces. Both need the same gate as a new route: a mechanism, a pre-registered rule and a cost model measured consistently.
* **Evidence**: P2.2 R2.0: the revived frozen-backflow control variate showed a falling cost ratio (0.90, 0.59, 0.60 at $M=16$, 24, 32), but its cost constant came from $N=20$, $M=80$ while its variances came from $N=4$, a hybrid model; the round-1 kill stood. P2.2 R5.1s: screened WIBJ, proposed after WIBJ failed, was flat in operations (0.21 to 0.10) with accuracy already beyond the 0.2 mHa target (about 0.29 mHa at $K=20$).
* **Scope and limits**: Two routes in one leaf.
* **Counter-evidence and open questions**: None.
* **How to use it**: Treat every revival or rescue as a new route: card it, gate it and pre-register its rule before measuring.
* **Sources**: P2.2 R2.0, R5.1s.

### L63. In drivers that import a frozen analysis script, set the OMP, OpenBLAS and MKL thread variables before the first numpy import, because BLAS reads them once at import and otherwise uses every core, overrunning CPU caps.
* **Status**: PROVISIONAL
* **Applies to**: interactive or batch runs under a CPU-time cap that wrap existing Python code using numpy, scipy or torch on shared nodes.
* **The lesson**: BLAS libraries fix their thread pools when numpy is first imported. A driver that imports a frozen script (or anything importing numpy) before setting `OMP_NUM_THREADS`, `OPENBLAS_NUM_THREADS` and `MKL_NUM_THREADS`, or that sets threads by a command-line flag after import, runs multi-threaded however the flag reads, and CPU time scales with the core count while wall time looks normal.
* **Evidence**: P4.1 R16/R17 `che` run (`tests/P4.1_cheap_su2_r26/t1_polished.py`): numpy imported before the thread variables were set; BLAS used 20 cores (988% CPU), 1128 s user time, that is 18.8 CPU-min against a 10 CPU-min hard cap, in 1 min 55 s wall (torch was single-threaded). After setting the variables before the import, the `pcg` run used 4.5 CPU-min on one thread. The same slip in round 22's first `guided.py` (12.0 CPU-min for 247 s wall). Both spends were unledgered.
* **Scope and limits**: One cluster, numpy with a threaded BLAS; libraries that read the variables lazily behave differently.
* **Counter-evidence and open questions**: None.
* **How to use it**: Put the thread variables at the top of every driver before any import (or in the job script), and compare user CPU time with wall time on the first run.
* **Sources**: P4.1 log `round-23-R16R17.md`, `round-23.md` section 8; `tests/P4.1_cheap_su2_r26/`, `tests/P4.1_cheap_su2_r25/guided.py`; L47, L49.
