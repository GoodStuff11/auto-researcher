# Personal notes (opt-in)
Only the folders listed under `notes:` in **your own** `hub.local.yaml` (e.g. `notes: [/home/me/obsidian/personal/research]`) — never another person's, never anything not listed. Watermark `notes.<me>` = the newest file mtime processed (YYYY-MM-DD).
1. List files in those folders modified on or after the watermark; for a file modified on the watermark day, check `hub seen notes:<me>@<date>` first and skip what is already recorded.
2. Keep only facts about this project: results, decisions you took, questions you opened. Summarise in your own words; never copy text verbatim; skip anything personal, career-related or about other people's performance.
3. Batch file: `safe` entries/log lines with source `notes:<me>@<YYYY-MM-DD>` (the note's mtime); anything that closes or decides → `proposals` (closure shape in `sources/circleback.md`). Actions found in notes are always proposals, never safe `new`. `owner` of any new item must be a people key (name unmapped people in the text instead). `watermark: {name: notes.<me>, value: "<newest mtime processed>"}`. Write the batch file in the scratch directory (outside the vault), then `hub ingest batch <file>`.
