# Personal notes (opt-in)
Only the folders listed under `notes:` in **your own** `hub.local.yaml` (e.g. `notes: [/home/me/obsidian/personal/research]`) — never another person's, never anything not listed. Watermark `notes.<me>` = the newest file mtime processed (YYYY-MM-DD).
1. List files in those folders modified on or after the watermark. Each file has its own source id `notes:<me>@<YYYY-MM-DD>-<slug>`: the file's mtime date, then its file name without extension, lowercased, every run of characters other than a-z and 0-9 replaced by one `-` (e.g. `HVA runs.md` modified 2026-11-17 → `notes:alice@2026-11-17-hva-runs`). Check `hub seen <that id>` for each file first and skip what is already recorded.
2. Keep only facts about this project: results, decisions you took, questions you opened. Summarise in your own words; never copy text verbatim; skip anything personal, career-related or about other people's performance.
3. Batch file: `safe` entries/log lines with the file's source id `notes:<me>@<YYYY-MM-DD>-<slug>` (step 1); anything that closes or decides → `proposals` (closure shape in `sources/circleback.md`). Actions found in notes are always proposals, never safe `new`. `owner` of any new item must be a people key (name unmapped people in the text instead). `watermark: {name: notes.<me>, value: "<newest mtime processed>"}`. Write the batch file in the scratch directory (outside the vault), then `hub ingest batch <file>` and `hub commit "status: notes.<me> (<YYYY-MM-DD>)"` (SKILL.md, update step 3).
